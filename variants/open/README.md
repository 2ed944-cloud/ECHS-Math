# ECHS Mathematics Open

This repository is the account-free presentation edition of ECHS Mathematics.

## Included

- Complete visible course catalogue
- Interactive lesson pages
- Practice Studio
- Review and Mistake Bank
- Tests and assessments
- Local progress, mastery, bookmarks and streaks
- Verified Official AP resource area

## Not included

- Student, teacher, parent or administrator accounts
- Sign-in or registration
- School rosters, classes or assignments
- Supabase configuration or private APIs
- Administration and account-management pages
- Cloud synchronization

All learning progress is stored locally in the visitor's browser. Clearing browser storage removes that local progress.

## Deployment

GitHub Pages deployment is handled by `.github/workflows/deploy-pages.yml`. The release validates that account and role surfaces are absent before deployment.

The intended public URL is:

`https://2ed944-cloud.github.io/ECHS-Math-Open/`
