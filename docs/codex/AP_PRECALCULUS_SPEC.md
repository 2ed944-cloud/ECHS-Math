# AP Precalculus Specification

## Active authority

Use the current College Board AP Precalculus Course and Exam Description for 2026–27 plus Fall 2026 clarifications/corrections.

Revalidate official exam format before release.

## Course identity

AP Precalculus centers on functions modeling dynamic phenomena.

The platform must make students think about:
- covariation;
- model choice;
- function behavior;
- parameters;
- transformations;
- multiple representations;
- assumptions/limitations;
- interpretation.

Do not reduce the course to Algebra 2 review.

## Units

### Unit 1
Polynomial and Rational Functions

### Unit 2
Exponential and Logarithmic Functions

### Unit 3
Trigonometric and Polar Functions

### Unit 4
Functions Involving Parameters, Vectors, and Matrices

Units 1–3 are assessed on the AP Exam.
Unit 4 is not assessed on the AP Exam.

Store this distinction in curriculum metadata.

## Mathematical practices

### Practice 1 — Procedural and Symbolic Fluency
Algebraically manipulate functions, equations, and expressions.

### Practice 2 — Multiple Representations
Translate mathematical information between representations.

### Practice 3 — Communication and Reasoning
Communicate precisely and support conclusions.

Use skill-level tags from the CED rather than only practice-level tags.

## Modeling/covariation rule

At least one substantial activity in most function-family topics should ask:
- what quantities vary;
- how they vary together;
- which representation exposes the relationship;
- why the model is reasonable;
- where the model may fail.

## Interaction expectations

### Polynomial
- degree/end behavior;
- zeros/multiplicity;
- turning behavior;
- parameter manipulation;
- difference quotient/rate trends when appropriate.

### Rational
- zeros;
- holes;
- vertical/horizontal asymptotes;
- end behavior;
- equivalent expressions;
- model limitations.

### Exponential
- multiplicative change;
- growth factor;
- percent rate;
- half-life/doubling;
- parameter meaning;
- linear vs exponential comparison.

### Logarithmic
- inverse relationship;
- scale interpretation;
- model transformations;
- solving with/without technology.

### Trigonometric
- unit-circle/periodic correspondence;
- amplitude/midline/period/phase;
- sinusoidal modeling;
- rate/covariation interpretation.

### Polar
- angle/radius tracing;
- rectangular/polar correspondence;
- parameter-based curve behavior.

### Unit 4
Parametric/vector/matrix experiences should remain clearly marked as non-exam Unit 4 if used.

## Question authenticity

AP-style Precalculus questions should combine the practices, not just use AP branding.

Strong items may ask students to:
- choose a model;
- interpret a parameter;
- construct an equivalent representation;
- infer behavior from data;
- compare representations;
- support a conclusion;
- solve with/without technology.

## Calculator policy

Question records require explicit:
- `calculator_not_permitted`;
- `calculator_required`;
- `calculator_optional` if the curriculum/test context permits.

If a question can be solved easily without the calculator, do not call it calculator-required merely because a graph is present.

## Dynamic parameter lab benchmark

A parameter explorer should support:
- sliders;
- exact current equation;
- graph;
- key features;
- table where valuable;
- reset;
- guided prompt;
- accessible text state.

Students should predict before moving the parameter when pedagogically appropriate.

## Mastery profile

Track:
- function family;
- practice;
- representation;
- modeling;
- calculator/technology;
- reasoning.

Example:
Student can symbolically solve exponential equations but cannot interpret growth-factor parameters in context.

The platform should surface that distinction.
