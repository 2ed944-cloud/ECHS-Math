# AP Calculus AB / BC Specification

## Active authority

Use the current College Board AP Calculus AB/BC Course and Exam Description for 2026–27 plus Fall 2026 clarifications/corrections.

Course content did not change in Fall 2026, but the multiple-choice count/timing changes beginning with the May 2027 exams.

Revalidate before every major curriculum release.

## Course identity

AP Calculus is a coherent study of:
- Change
- Limits
- Analysis of Functions

It must not become a list of differentiation/integration tricks.

## Mathematical practices

Tag lesson and assessment evidence using:

1. Implementing Mathematical Processes
2. Connecting Representations
3. Justification
4. Communication and Notation

A strong unit contains evidence across multiple practices.

## Representation profile

Track:
- analytical;
- graphical;
- numerical/tabular;
- verbal/contextual.

A student may master a topic algebraically but not graphically. The platform should expose that difference.

## AB / BC course mapping

Use a shared core with explicit AB/BC scope metadata.

AB:
- Units 1–8.

BC:
- Units 1–10, including BC extensions in shared units and BC-only Units 9–10.

Never show a BC-only objective as AB because a lesson happens to contain it.

## May 2027 exam configuration

Store this as configuration, not hard-coded components.

### MCQ
42 questions, 1h 40m, 50%
- Part A: 29, 62m, calculator not permitted
- Part B: 13, 38m, graphing calculator required

### FRQ
6 questions, 1h 30m, 50%
- Part A: 2, 30m, graphing calculator required
- Part B: 4, 60m, calculator not permitted

Exam items include multiple function types and analytical/graphical/tabular/verbal representations.

## Lesson standard

Every major AP lesson should include the subset appropriate to the topic:

1. conceptual hook;
2. prior-knowledge signal;
3. exploration;
4. precise definition/theorem;
5. representation connection;
6. worked example;
7. guided check;
8. original AP-style MCQ;
9. original AP-style FRQ/justification when appropriate;
10. misconception check;
11. challenge;
12. exit evidence.

Do not mechanically force every element if the mathematics does not need it.

## Question authenticity rubric

Before labeling a question `AP-style`, verify:

### Alignment
- exact unit/topic/objective;
- correct mathematical practice;
- correct calculator policy.

### Structure
- stem is concise;
- no irrelevant exposition;
- representations are authentic;
- notation matches AP conventions;
- contextual units matter where present.

### Cognitive demand
The item should require one or more of:
- choose/execute a process;
- connect representations;
- interpret a quantity;
- justify a conclusion;
- communicate with correct notation.

### Distractors
For MCQ, derive from real misconceptions rather than random values.

### Originality
No copied protected prompt.

## Interactive component expectations by unit

### Unit 1 — Limits and Continuity
Reusable components:
- secant-to-tangent explorer;
- left/right table generator;
- hole/jump/asymptote graph explorer;
- squeeze theorem visualizer;
- continuity condition checker;
- IVT interval explorer.

### Unit 2 — Differentiation: Definition and Fundamental Properties
- derivative-from-local-linearization explorer;
- tangent slope scrubber;
- symbolic/numerical/graphical derivative correspondence.

### Unit 3 — Composite, Implicit, Inverse
- chain-rule composition map;
- implicit curve tangent explorer;
- inverse function derivative pairing.

### Unit 4 — Contextual Applications
- units/meaning composer;
- related-rates geometry that updates dynamically;
- motion graph coordination.

### Unit 5 — Analytical Applications
- derivative sign chart linked to graph;
- extrema/critical-point explorer;
- concavity/inflection explorer;
- optimization constraint visualizer.

### Unit 6 — Integration and Accumulation
- signed-area explorer;
- Riemann-sum refinement;
- accumulation function;
- FTC correspondence;
- numerical integration comparison.

### Unit 7 — Differential Equations
- slope-field interaction;
- solution-curve seed;
- Euler method stepper;
- separable model comparison.

### Unit 8 — Applications of Integration
High priority:
- area between curves;
- cross sections;
- disk/washer;
- shell;
- average value;
- motion accumulation.

Use the 3D engine for spatial volume/cross-section ideas.

### Unit 9 — BC Parametric/Polar/Vector
- synchronized parameter/position/velocity;
- polar trace;
- polar area sectors;
- arc-length geometric interpretation.

### Unit 10 — BC Sequences/Series
- partial sum explorer;
- convergence comparison;
- error-bound visualization;
- Taylor polynomial approximation;
- radius/interval convergence explorer.

## Volume benchmark

For disk/washer/shell lessons, the ideal advanced layout is:

2D region | mathematical setup | 3D solid

Interactions can include:
- move representative slice;
- rotate solid;
- show/hide region;
- show/hide axis;
- show outer/inner radius;
- show shell radius/height;
- animate construction;
- switch methods when mathematically valid.

Do not let visual scale imply an incorrect radius.

## FRQ response experience

Student workspace should support:
- typed math where appropriate;
- handwritten/upload workflow only if institutionally supported;
- multi-part response;
- “justify” reminder based on command;
- units field/feedback only after submission when pedagogically appropriate;
- calculator/non-calculator mode.

Rubrics/scoring guides:
- hidden until release;
- distinguish ECHS classroom rubric from official College Board scoring guideline;
- support evidence tags by practice.

## Mastery

Track AP topic mastery separately from representation/practice.

Example:
`Unit 6 Topic X = Secure`
but:
`Connecting Representations = Developing`

This is more useful than one unit percentage.
