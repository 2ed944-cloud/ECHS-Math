# Qatar Identity and Context Specification

## Principle

Local identity should strengthen relevance without weakening curriculum rigor.

A Qatar-context question must remain valid if the context is removed and the underlying mathematics is inspected.

## What not to do

Do not:
- add a flag beside unrelated algebra;
- insert a landmark photo into every lesson;
- fabricate data;
- claim a building follows an exact function without evidence;
- replace AP/IB wording conventions with promotional language;
- make context so complicated that it tests reading instead of mathematics.

## Context architecture

Separate:

### Mathematics model
The actual function/data/geometry.

### Context asset
Qatar story, dataset, labels, units, source.

### Visual asset
Image/diagram/icon.

### Pedagogical note
Why this context helps.

This allows:
- neutral version;
- Qatar version;
- future alternate contexts.

## Context categories

- Doha Metro / transport;
- Education City;
- Lusail;
- climate/temperature;
- solar energy;
- water;
- population/demography;
- sports;
- aviation/trajectory;
- architecture;
- Islamic geometric patterns;
- dhow navigation;
- pearl-diving history;
- public-space flow;
- finance/economics using authoritative data.

Use only when appropriate to the objective.

## Dataset governance

Dataset record:
- title;
- source;
- source URL/reference;
- publication date;
- retrieval date;
- units;
- raw data;
- transformations;
- license/use note;
- context explanation.

Do not silently update a dataset and change question answers.

Version datasets.

## AP Calculus examples

### Rates
Passenger flow model at a transit station.

### Accumulation
Water/energy inflow-outflow model.

### Differential equations
Idealized cooling/temperature model, explicitly labeled as a model.

### Volume
Architectural-inspired mathematical model, clearly described as an approximation rather than an exact building geometry.

## AP Precalculus examples

### Exponential
A growth/decay context with sourced or explicitly fictionalized data.

### Periodic
Temperature/daylight periodic models.

### Polynomial/rational
Engineering/geometry models with natural domain restrictions.

### Polar
Pattern/geometry investigation inspired by regional design, without claiming historical geometry that is not sourced.

## IB AI SL examples

High-value uses:
- real datasets;
- regression;
- statistics;
- finance;
- networks;
- geometry;
- optimization;
- interpretation.

IB contexts should encourage evaluation of model limitations.

## Context toggle

Where practical:
`Context: Neutral | Qatar`

The skill/objective should remain stable.

Do not generate a Qatar version if the new context changes the target cognitive demand materially.

## Design identity

Use Qatar influence subtly:
- maroon;
- ivory;
- charcoal;
- restrained warm accent;
- geometric line motifs;
- premium spacing/typography.

Accessibility overrides brand colors.

## Content review

Before publishing Qatar context, verify:
- factual accuracy;
- cultural appropriateness;
- data/source;
- correct units;
- mathematical authenticity;
- no overclaim;
- curriculum alignment.

## Authoring

Lesson Studio “Qatar Context” assistant may:
- search approved context library;
- insert a reviewed dataset;
- create a draft variant;
- show source.

AI-generated contextual claims must be fact-checked before publication.
