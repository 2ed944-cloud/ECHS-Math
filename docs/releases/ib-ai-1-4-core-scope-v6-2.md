# IB AI SL Lesson 1.4 — Core-first scope release 6.2.0

## Reason for the correction

The complete Financial Applications lesson intentionally combines several related financial contexts, but the default student route had become broader than the current IB Mathematics: Applications and Interpretation SL syllabus requires.

The current course separates the required financial content into:

- **SL 1.4** — financial applications of geometric sequences and series: compound interest and annual depreciation;
- **SL 1.7** — loan repayments and amortization.

The supplied Pearson, Haese and MAI 2.19 references contain additional useful financial applications, including regular deposits, annuity timing, withdrawal funds, inflation, real value, outstanding balances and broader decision analysis. These remain valuable teaching and enrichment resources, but they should not all appear as prerequisites for typical SL mastery.

## New default student route

The unchanged lesson URL now opens in **IB SL Core** mode. The default Learn path emphasizes:

1. percentage factors and financial growth;
2. simple versus compound change;
3. nominal and periodic rate conventions;
4. compound-interest calculations and completed-period thresholds;
5. annual reducing-balance depreciation;
6. finance-solver variables and cash-flow signs;
7. loan repayments, total repayment and total interest;
8. amortization schedules and the interest–principal split;
9. basic comparison of loan term, payment size and affordability;
10. synthesis, exit evidence and mastery.

## Reference-supported extension

The following existing material is retained and marked **Extension**:

- effective annual rates;
- inflation and real value;
- regular-deposit annuities;
- annuities due;
- mixed deposits;
- savings thresholds;
- withdrawal and retirement funds;
- formula derivations for annuity and loan payments;
- retrospective and prospective outstanding balances;
- extra-payment strategies;
- sensitivity and risk analysis;
- growing annuities.

Students or teachers can restore the complete 100-screen route from the **All content** control in the lesson header. The same switch restores the full Practice Studio, Timed Quiz and IB Task collections.

## Production preservation

- The lesson remains one lesson at the canonical URL.
- All 100 Learn screens remain stored in their original order.
- All 120 Practice Studio questions, 16 Quiz questions and 6 IB Tasks remain stored.
- Existing mathematics, KaTeX, screen HTML, graphics, interactions, answers and IDs are preserved.
- Canonical slide indices and local response keys remain stable.
- The core route skips extension screens rather than deleting or renumbering them.
- Mastery evidence in the default mode is calculated only from the core route and core assessment subset.

## Course-version note

This alignment targets the current Mathematics: Applications and Interpretation course used for the 2026–2027 teaching context. The revised IB mathematics courses begin first teaching in August 2027 for first assessment in May 2029 and should be handled as a separate future migration rather than silently changing the current production course.
