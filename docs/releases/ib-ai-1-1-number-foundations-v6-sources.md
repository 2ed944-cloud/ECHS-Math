# Source basis

The release extends the existing lesson while retaining its documented source basis:

- Pearson, *Mathematics: Applications and Interpretation SL* — number and algebra foundations;
- Haese Mathematics, *Mathematics: Applications and Interpretation SL 2* — approximation, bounds and error;
- supplied Nikolaidis Topic 1A and MAI materials — number sets, rounding, scientific form and percentage error.

The lesson text and assessment items are original ECHS adaptations. The stable platform lesson and mastery mapping remain unchanged.
