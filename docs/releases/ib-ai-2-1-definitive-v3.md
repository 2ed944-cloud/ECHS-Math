# IB Mathematics AI SL Lesson 2.1 — Definitive release 3.0.0

## Release purpose

Lesson 2.1 has been rebuilt as the conceptual foundation of Unit 2. The previous lesson contained a broad 64-screen sequence, but several screens repeated a generic representation graphic and the instructional route did not sufficiently distinguish the current IB SL core from later inverse, composition and advanced-domain work.

The definitive release preserves the canonical lesson URL and all existing public assessment IDs while replacing the Learn route with a coherent, classroom-ready progression.

## Current IB SL alignment

The default pathway is aligned to the current Mathematics: Applications and Interpretation function requirements represented in the supplied curriculum mappings:

- **SL 2.2** — functions, notation, domain, range and inverse as reflection;
- **SL 2.3** — graph of a function;
- **SL 2.4** — key features of graphs and intersections using technology.

The lesson is also grounded in the supplied Pearson, Haese, Topic 2A and current question-bank mapping resources. These sources support the progression from relations and function notation to domain, range, graphs, technology and contextual modelling.

## Five classroom teaching blocks

### 2.1A — Relations and the Function Rule

- relations, functions and the one-output rule;
- mapping diagrams, tables and ordered pairs;
- vertical-line test;
- repeated-input and repeated-output misconceptions;
- implicit-relation and domain-restriction extension.

### 2.1B — Function Notation, Images and Preimages

- evaluation by substitution;
- images and preimages;
- table and graph interpretation;
- independent and dependent variables;
- equivalent representations;
- parameter and composition previews as extension.

### 2.1C — Domain and Range

- mapping, table, graph and formula evidence;
- interval, inequality and set-builder notation;
- open and closed endpoints;
- denominator and square-root restrictions;
- contextual and discrete domains;
- range from endpoints, extrema and open bounds;
- combined restrictions and reciprocal range as extension.

### 2.1D — Reading Features of Graphs

- intercepts and zeros;
- local and global extrema;
- increasing, decreasing and constant intervals;
- positive and negative intervals;
- endpoints, holes and jumps;
- trace, table, window and intersection evidence;
- tariff and continuity extension.

### 2.1E — Technology, Inverse Reflection and Modelling

- transparent GDC workflow;
- interactive restricted-domain laboratory;
- rule-of-four validation;
- delivery-fee modelling inquiry;
- inverse relation as coordinate swap and reflection in `y=x`;
- informal one-to-one reasoning;
- algebraic inverse, piecewise boundary design and sensitivity extension.
