# AP Calculus 1.6 — interactive algebraic limits

Lesson 1.6 now follows the ECHS slide format used in Lessons 1.1–1.4. Its 44 slides teach an AP-aligned core before AP-style practice, an AP exit check, and a separate Challenge & Extra section. There are 38 objective checks (16 AP-style MCQs, 16 challenge MCQs, and six guided/exit checks), three AP-style FRQs, six challenge FRQs, and nine interactive investigations. Every challenge question is an MCQ or FRQ.

The core follows Topic 1.6, LIM-1.E.1 and suggested practice 1.C: equivalent expressions obtained through factoring, square-root conjugates, common denominators and exact trigonometric identities. It uses prerequisite limit laws from Topic 1.5. The harder sine-anchor questions supply the radian limit as an assumption; the anchor's squeeze-theorem proof is explicitly connected to Topic 1.8 rather than included as required Topic 1.6 content. Framework scope was verified against the College Board AP Calculus AB and BC Course and Exam Description, Topic 1.6, PDF page 43, in September 2026.

The extensions retain general x^n−a^n limits, common-root substitutions, synthetic division with zero coefficients, repeated factors, square-root and cube-root rationalization, nested radicals, trigonometric cancellation and scaling, parameter finding, and the requested inequality. Both real negative cube-root inputs and the exceptional target zero are handled. The prior polynomial x^4−5x^3+3x^2+9x−8 has remainder −8 at x=3; it is now an explicit synthetic-division error-analysis question, alongside valid cancellation examples.

The user's clarified inequality uses (x+3)/(x^2+ax+b), not x−3 in the numerator. If its limit at 3 is not finite, the denominator must satisfy 9+3a+b=0. The main FRQ uses the user's requested squaring argument: 3a+b=−9 implies 9a^2+6ab+b^2=81; because a and b cannot both be zero, 81−6ab=9a^2+b^2>0, giving ab<27/2. An optional part completes the square to obtain the sharp bound ab≤27/4 and verifies that a=−3/2, b=−9/2 is a counterexample to the strict claim ab<27/4. The parameter explorer also handles a=−6, b=9, where both one-sided limits are positive infinity and the limit is not a finite real number.
