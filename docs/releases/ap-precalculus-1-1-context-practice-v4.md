# AP Precalculus 1.1: context practice, release 4.0.0

The six supplied reference types required more guided practice connecting rate descriptions, function graphs and physical contexts. This update adds 48 original four-option questions with different data and independently written stems, distractors, hints and solutions. It retains the existing lesson and its recent heading-focus fix.

| Family | New questions | Placement |

| Direction and concavity together | 8 | After the rate-table skill explanation |
| Rate behavior from a curve | 8 | After the graph-rate explanation and new curve investigation |
| Circular motion and wall distance | 8 | After contextual graph construction and the new toy-car investigation |
| Constant-inflow vessels | 8 | After the vessel explanation and filling investigation |
| Projectile height and elapsed time | 8 | After calculator graph reading, worked timeline and flight investigation |

The lesson now has 82 slides, 12 investigations, 6 formative checks, 72 AP-style MCQs, 4 challenge MCQs and the existing 6 six-point written tasks. The practice menu links directly to the prerequisite for each new family. The additional practice is intended for use across classes or targeted practice sessions.

The car model pairs a geometric track diagram with a distance–time graph. Play/pause, reset, quarter-lap stepping, time scrubbing, full-graph reveal and changes to radius, wall gap, starting point, lap period and lap count are supported. Uniform speed is explicit; the car is modeled as a point. Motion stops when the lesson slide or document is hidden.

The vessel model uses circular horizontal cross-sections, exact piecewise-linear cross-sectional areas, conserved volume and inversion of the volume function to find depth. It includes five shapes and three constant inflows. The curve model highlights intervals crossing turning points without requiring derivative formulas. The projectile model ends at first ground contact and distinguishes elapsed time after release from descent duration after maximum height.

All new question answers use the existing attempt-gated solution and account-scoped response system. Changing a lab setting or response invalidates feedback and hides its explanation. New response revision v4 avoids mapping stored slide numbers onto the expanded slide sequence. Existing saved v3 data is retained under its original key.
