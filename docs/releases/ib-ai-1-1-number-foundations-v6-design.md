# Design principles

- AP-style full-screen lesson composition with a fixed platform header and internal slide navigation.
- Every screen has a defined instructional purpose: definition, modelled example, student transfer, misconception diagnosis, checkpoint or assessment.
- Mathematics is rendered through KaTeX without styling internal KaTeX spans.
- Diagrams use stable HTML/CSS components rather than inline SVG.
- Interactive components preserve student responses locally and support keyboard and mobile use.
