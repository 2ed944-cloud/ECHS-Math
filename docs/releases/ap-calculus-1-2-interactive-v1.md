# AP Calculus 1.2 — interactive lesson rebuild

The previous lesson mixed the meaning of limit notation with substantial later-topic and beyond-AP material, including formal epsilon–delta proofs. The legacy entry point also opened a different lesson. This rebuild gives Topic 1.2 a coherent sequence using the interactive slide design established in Lesson 1.1.

- 35 responsive slides with keyboard navigation, focus mode, printable student content and a slide menu.
- Six investigations: approaching a target, changing one point, a six-scenario notation builder, linked representations, independently adjustable one-sided limits, and local versus distant behavior.
- 24 objective questions, including 16 original AP-style MCQs; optional hints and attempt-gated worked solutions.
- Three original free-response tasks with nine-point classroom rubrics, editable drafts and explicitly self-assessed marks. Editing a response invalidates its previous self-assessment.
- Two construction/evidence challenges, a contextual translation task and an exit ticket.
- Account-scoped device drafts, reset confirmation and graceful handling of unavailable storage. Protected platform progression remains the authority for completion and mastery.
- Legacy URL redirects to the canonical lesson while retaining access query parameters and the slide fragment. Course metadata and the service-worker version reflect the release.

Alignment was checked against College Board's AP Calculus AB and BC Course and Exam Description on 4 September 2026: Topic 1.2, LIM-1.A, LIM-1.B and mathematical practice 2.B. Simple one-sided notation is identified as a bridge to Topic 1.3. Formal epsilon–delta proofs and later calculation techniques are outside the core sequence. Questions and rubrics are original classroom materials, not official exam items or scoring guidelines. Existing companion PDFs are unchanged separate resources.

Validation includes independent numerical checks of the six model families, zero and missing-value handling, 24 answer keys, all rubric structures, 166 authored KaTeX expressions and dynamically generated equations. DOM-level tests execute the actual lesson scripts through every investigation and question, navigation, attempt/rubric gates, draft changes, account isolation, reset and denied storage. No browser automation or production account is used. The deployment workflow runs these checks alongside Lesson 1.1 and the existing access, visibility and local-link gates.
