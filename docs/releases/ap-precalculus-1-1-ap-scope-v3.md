# AP Precalculus 1.1: Change in Tandem, release 3.0.0

The previous lesson contained a small AP practice set, unscored written guidance and an unstructured challenge section. The revised lesson develops the complete Topic 1.1 scope through linked representations, exact mathematical models and original topic-focused AP-style practice.

## Curriculum basis

Reviewed against the College Board AP Precalculus Course and Exam Description effective Fall 2026, Topic 1.1 (printed pages 29–30), and the introductory-fluency guidance in Appendix B:

https://apcentral.collegeboard.org/media/pdf/ap-precalculus-course-and-exam-description.pdf

| Framework | Lesson coverage |
| --- | --- |
| 1.1.A.1 | Function definition, variables, domain/range, equal functions requiring equal domains and outputs |
| 1.1.A.2 | Verbal, analytical, numerical and graphical representations; images and complete preimage sets |
| 1.1.A.3–4 | Pairwise comparisons; increasing/decreasing behavior; direction distinct from sign |
| 1.1.B.1–2 | Paired input/output graphs; contextual graph construction |
| 1.1.B.3–4 | Qualitative concavity; output direction distinct from increasing/decreasing rate |
| 1.1.B.5 | Zeros as input values; x-intercepts as points; contextual interpretations |
| Skills 2.B and 3.A | Connecting representations and reporting exact versus approximate features appropriately |

Open versus closed endpoint notation is not assessed for increasing/decreasing intervals. Exact domain and preimage endpoints remain relevant. Quantitative average-rate-of-change calculations belong to Topic 1.2. No calculus prerequisites, regression tasks or unrelated advanced algebra are required.

## Delivered experience

- 48 navigable slides; local KaTeX; responsive SVG graphs and keyboard-friendly controls.
- Eight investigations: reservoir covariation, mapping a function, preimages and domain restrictions, direction versus sign, four concavity combinations, contextual graph construction, finite-data counterexamples, and calculator graph reading.
- Six formative checks followed by 24 original AP-style MCQs and four six-point FRQs.
- Four challenge MCQs and two six-point challenge FRQs follow the main AP-style work. Challenges concern equality, preimages, limits of finite evidence, and constructions satisfying Topic 1.1 constraints.
- Every MCQ includes a hint, feedback and an attempt-gated worked solution. Written tasks have 18 two-point parts, attempt-gated scoring guidelines and 36 possible self-assessed points.
- Written reasoning is not automatically graded. Lesson interactions do not confer platform mastery. These original topic-focused tasks use AP-style presentation; they are not official released questions or complete full-course exam simulations.
- Revised responses require renewed answer checking or rubric review; account-scoped storage isolates responses by account and lesson revision. Storage denial is handled gracefully.
- Canonical URL retained. Legacy redirects retain query parameters and hashes; old named slide links map to corresponding new material. Protected practice continuation delegates to the platform access control.
- Existing companion PDFs remain separate earlier resources and are labeled accordingly. Updated practice links point directly into the revised lesson.
