# IB Mathematics AI SL Lesson 1.4 — Core-First Scope Release 6.2.0

## Purpose

Lesson 1.4 remains one production lesson at the same canonical URL. Release 6.2.0 changes the default learning scope so a typical Mathematics: Applications and Interpretation SL student meets the current SL 1.4 core before broader financial applications.

## Scope evidence

The current syllabus mapping identifies SL 1.4 as financial applications involving compound interest and annual depreciation. The wider supplied references include regular deposits, annuities, loans, amortization, inflation, real value and financial comparisons. These broader applications are valuable, but they are no longer presented as equal-weight prerequisites for default SL 1.4 mastery.

## Default IB SL core

The default route contains:

- 31 Learn screens
- 40 Practice Studio questions
- 10 Timed Quiz questions
- 3 IB-style extended tasks
- four teaching blocks: 1.4A–1.4D

The learning sequence is:

1. percentage factors and compound growth;
2. compounding conventions and completed periods;
3. annual reducing-balance depreciation;
4. transparent technology and core mastery.

## Optional broader applications

The same lesson exposes an optional route through `?scope=extension`. It retains:

- 71 Learn screens
- 80 Practice Studio questions
- 12 Timed Quiz questions
- all 6 original IB tasks
- teaching blocks 1.4E–1.4G

This route contains effective rates, inflation, real value, regular deposits, annuities, withdrawal funds, loans, amortization, outstanding balances, repayment strategy, sensitivity and risk.

## Preservation

- The canonical lesson URL and route hashes remain valid.
- All 100 original Learn screens remain available across the two scopes.
- All 120 original Practice Studio questions remain available and are partitioned without duplication.
- All original advanced assessment tasks remain available in the optional route.
- Existing lesson graphics, CSS and core platform design remain unchanged.
- Core and extension progress are saved independently to prevent a long optional route from distorting core mastery evidence.
