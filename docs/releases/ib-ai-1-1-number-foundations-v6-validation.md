- JavaScript syntax checks for every data and interaction layer;
- exact assembled counts: 79 Learn screens, 96 Practice questions, 14 quiz questions and 5 IB tasks;
- 24 Practice questions in each of Foundation, Application, Reasoning and Challenge;

- mathematical recomputation of water-tank and optical-component bounds;
- no inline SVG in lesson content;
- no CSS selectors that mutate KaTeX internal spans;
- preservation of assessment scrolling and platform access integration.
