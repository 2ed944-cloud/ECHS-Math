# IB AI SL Lesson 1.1 — merged SL 1.1 + SL 1.6

The canonical Lesson 1.1 keeps scientific notation and approximation/error in one lesson. Its rebuilt sequence is scoped to the current Mathematics: Applications and Interpretation SL syllabus, first assessed in 2021 and applicable before the 2029 revision.

| Official section | Lesson coverage |
| --- | --- |
| SL 1.1 | Normalized scientific notation, conversion and the four arithmetic operations |
| SL 1.6 | Decimal places, significant figures, appropriate accuracy, estimates, error intervals, simple calculated bounds and percentage error |

The lesson contains 43 slides, eight investigations, 12 immediate-feedback learning checks and 14 original IB-style written tasks. The written pool contains eight short-response tasks, three extended-response tasks and three relevant SL challenges: 46 parts worth 82 marks. This is a practice collection, not a mock examination paper. The existing catalog field extended_tasks counts all 14 written tasks for compatibility; the new assessment metadata records their actual formats separately.

Questions specify their requested form, accuracy, units and reference values. The challenge sequence follows the main IB-style practice. It retains rounding carry, endpoint reasoning and precision versus accuracy; the carry question's separate error-interval part explicitly specifies rounding to the nearest 0.0001 m.

TI-Nspire CX / CX II instructions cover Calculator entry, parentheses and exponent templates, floating display, Auto mode, Ctrl + Enter and retaining unrounded intermediate values. The local coach checks fixed examples and is labeled guided practice. It is not represented as a TI emulator. Older lesson overlays and external TI-84 assets are no longer loaded by the canonical lesson.

Learning checks enforce normalized notation, decimal places and significant figures. Written work has attempt-gated classroom markschemes with variable M/A/R marks and self-assessment. Editing clears a prior self-assessment; responses are scoped to account and lesson revision. No lesson views or self-assessed marks automatically award platform mastery.

The canonical URL and merged approximation redirect remain available. Query parameters survive the redirect, legacy practice/exam anchors resolve to the revised sequence, and continuation delegates to the protected platform practice action. Earlier companion notes are explicitly labeled as earlier editions.
