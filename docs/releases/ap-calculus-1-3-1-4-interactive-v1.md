# AP Calculus 1.3 and 1.4 — interactive rebuild

The previous lessons mixed core graph/table estimation with beyond-AP material, and their legacy URLs led to different topics. Both now use the interactive slide format established in Lessons 1.1 and 1.2.

Each lesson has 35 slides, six investigations, 24 objective checks (including 16 original AP-style MCQs), three original free-response tasks with nine-point classroom rubrics, two challenges and an exit ticket. Hints, attempt-gated solutions, written drafts and self-assessed rubric marks support independent or classroom use. Drafts are scoped by account and lesson; edited written work invalidates prior self-assessment. Existing protected platform actions remain authoritative for progression and mastery.

Lesson 1.3 develops LIM-1.C.1–4 and practice 2.B: tracing one-sided heights, open/filled points, graph construction, window limitations, unbounded branches, persistent versus shrinking oscillation, and multiple targets on one graph. Graphs use separate branches, readable numerical scales, adaptive reciprocal sampling, and a clearly identified unresolved central region for rapid oscillation. Exact sample families support conclusions beyond plot resolution.

Lesson 1.4 develops LIM-1.C.5 and practice 2.B: input design, progressive table revelation, one-sided comparisons, precision, calculator-style numerical exploration and misleading sampling. It distinguishes missing point values from unlisted values, finite estimates from unbounded trends, and numerical evidence from proof. Radian/degree mode comparison is explicit. Tables retain adequate input precision independently of rounded output precision.

Scope was checked against College Board's AP Calculus AB and BC Course and Exam Description in September 2026. Questions and rubrics are original classroom materials, not official exam items or scoring guidelines. Existing companion PDFs remain separate resources. Legacy redirects retain the query parameters used for access and the slide fragment. The course metadata and service-worker revision are updated.

Validation executes the actual lesson scripts in DOM fixtures, with all 48 objective answers, all 12 investigations, real local KaTeX rendering, navigation, rubric gates, draft invalidation, account/lesson isolation, denied storage, reset and protected continuation. Independent mathematical tests check graph limits, branches, exact oscillation samples, table models, input ordering, numerical precision and sampling counterexamples. The 93 authored model/content expressions parse through the bundled math renderer. Existing access, visibility and local-reference contracts are retained, and deployment runs these checks alongside Lessons 1.1 and 1.2. No browser automation or production student account is used.
