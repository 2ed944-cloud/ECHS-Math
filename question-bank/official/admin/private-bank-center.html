Simple protected workflow

Upload, validate, and connect

The Teacher Upload Manager replaces local Python and Terminal commands.

1

Choose the course

Use auto-detect or select AP Calculus. The manager records the expected course with the upload request.

2

Validate the manifest

The processor checks ZIP integrity, target courses, question mappings, rights, trust metadata, IDs, answers, and private media.

3

Import privately

Questions and media are written to private Supabase tables and storage, then become available through authenticated practice.

Publisher and source metadata stay internal. Students see neutral ECHS aliases such as AP Calculus Bank 1. Publisher-key direct practice is not independently audited unless the package records independent verification. Source content and media are never published through GitHub Pages.
