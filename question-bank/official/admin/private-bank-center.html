Simple protected workflow

Upload, validate, and connect

The Teacher Upload Manager replaces local Python and Terminal commands.

1

Choose exactly one course

The selected course must match the package manifest. Auto-detection and multi-course bank packages are no longer accepted.

2

Validate every route

Each question must carry one verified mapping with a course, unit, lesson key, lesson title and skill key.

3

Publish into its own lane

The bank appears only inside its declared course and only under units and lessons actually present in its mapping inventory.

Publisher and source metadata stay internal. Students see neutral ECHS aliases. Publisher-key direct practice is not independently audited unless its package records independent verification. Source content and media are never published through GitHub Pages.
