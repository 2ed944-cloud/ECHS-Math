# ECHS question-bank publication authorizations

This directory records authorization evidence used by the release gate.

An authorization record permits publication only within its stated scope. It does
not make source material public domain, does not erase provenance, and does not
override mathematical, transcription, KaTeX, media, calculator, mapping, or
structural verification requirements.

The active AP Calculus authorization is linked to GitHub Issue #56. Records that
do not pass every content gate remain excluded from student delivery even when
their publication scope is authorized.
