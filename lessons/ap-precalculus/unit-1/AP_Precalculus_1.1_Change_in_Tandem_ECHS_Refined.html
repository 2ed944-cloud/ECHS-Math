Domain, Range, and the Two Variables

Name the quantities before interpreting the mathematics.

Domain

The set of allowable input values.

Independent variable

The variable representing the input quantity.

Range

The set of output values actually produced.

Dependent variable

The output quantity whose value depends on the input.

Context example

The volume \(V\), in liters, of water in a tank is a function of elapsed time \(t\), in minutes.

Independent variable\(t\), measured in minutes Dependent variable\(V(t)\), measured in liters

The point \((12,450)\) means: after 12 minutes, the tank contains 450 liters.

AP writing habit

Include variable names and units. Avoid saying only “the graph goes up.”

When Are Two Functions Equal?

The formula is not the whole function.

Two functions \(f\) and \(g\) are equal only when they have the same domain and \[ f(x)=g(x) \] for every input in that domain.
Equivalent expressions

\(f(x)=2(x+3)\) and \(g(x)=2x+6\), both on \(\mathbb R\).

Because \(2(x+3)=2x+6\) for every real \(x\), \(f=g\).

Same formula, different domain

\(p(x)=x^2\) on \(\mathbb R\), while \(q(x)=x^2\) on \(x\ge0\).

\(p(-2)\) exists but \(q(-2)\) does not, so \(p\ne q\).

AP trap

Same range, one shared point, or the same variable name is not enough to prove two functions are equal.

Behavior Essential Knowledge 1.1.A.3–4 No calculator

Increasing and Decreasing Are Pairwise Statements

Read from left to right as the input increases.

Increasing on a region

Whenever \(a<b\) in that region,

\[ f(a)<f(b). \]

Larger inputs correspond to larger outputs.

Decreasing on a region

Whenever \(a<b\) in that region,

\[ f(a)>f(b). \]

Larger inputs correspond to smaller outputs.

AP interval note

Focus on identifying where the behavior occurs. Topic 1.1 does not assess the distinction between open and closed endpoint notation for these intervals.

Concavity Describes How the Rate of Change Is Changing

Direction and concavity answer different questions.

Concave up

The rate of change is increasing.

Slopes become more positive—or less negative—as input increases.

Concave down

The rate of change is decreasing.

Slopes become less positive—or more negative—as input increases.

Question 2Does the graph become steeper or flatter?Concavity

A graph can be increasing and concave down, or decreasing and concave up.

Zeros Essential Knowledge 1.1.B.5 No calculator

A Zero Is an Input; an \(x\)-Intercept Is a Point

Both describe where the output equals zero.

Zero

\[ f(c)=0 \quad\Longleftrightarrow\quad c\text{ is a zero of }f. \]

The zero is the input value \(c\).

\(x\)-intercept

\[ (c,0) \]

The intercept is the corresponding coordinate point.

Zeros Analytical representation No calculator

Find Zeros from a Factored Rule

Each factor can make the output zero.

Example
\[ g(x)=(x+2)(x-1)(x-3) \]
\(x+2=0\)\(x=-2\)
\(x-1=0\)\(x=1\)
\(x-3=0\)\(x=3\)

Zeros: \(\{-2,1,3\}\)

\(x\)-intercepts: \((-2,0),(1,0),(3,0)\)

Language check

Do not report the point \((3,0)\) when the question asks for the zero. The zero is \(3\).

A single relationship should survive every translation.

Analytical

\[ P(x)=4(x-5)(x+1) \]

Guaranteed graphical features

The output is zero at \(x=5\) and \(x=-1\), so every graph must contain \((5,0)\) and \((-1,0)\).

FRQ 1: Battery Performance

Use numerical and contextual representations without calculating average rate of change.

A rechargeable battery’s remaining energy \(E(t)\), in watt-hours, is measured at selected times \(t\), in hours.

\(t\)012345
\(E(t)\)806858504440
  1. Identify the independent and dependent variables and their units.
  2. Compare \(E(1)\) and \(E(4)\), then interpret the comparison.
  3. Describe the change in tandem shown by the listed values.
  4. The successive changes become less negative. What concavity does the data suggest?
  5. State one limitation of using only the six table entries.
Reveal scoring checkpoints

✓ t (hours) is independent; \(E(t)\) (watt-hours) is dependent.

✓ \(E(1)=68>44=E(4)\); 24 more watt-hours remain at hour 1.

✓ For listed times, energy decreases as time increases.

✓ Decreases become smaller in magnitude, suggesting concave up.

✓ The table does not show every value between recorded times.

Challenge: Equal-Looking Is Not Equal

Build examples that separate range, formula, and domain.

Same domain and same range

Give two different functions with domain \(\{-1,1\}\) and range \(\{0,2\}\) that are not equal.

Reveal one construction

Let \(f(-1)=0,f(1)=2\), but \(g(-1)=2,g(1)=0\). Same domain and range; different output at each input.

Same formula, different domain

Create two functions using the same analytical rule but different domains. Identify an input belonging to only one domain.

Reveal one construction

\(p(x)=x^2\) on \(\mathbb R\), \(q(x)=x^2\) on \(x\ge0\). The input \(-2\) belongs only to the domain of \(p\).

Challenge: State Only What the Visual Evidence Supports

Precision is part of mathematical correctness.

Responsible statement

“The graph appears to become nearly horizontal around \(x=5\).”

This respects the low resolution and uses approximate language.

Too strong without better evidence

“The function is exactly constant for every \(x\ge5\).”

A blurry or partial graph cannot establish exact long-term behavior.
