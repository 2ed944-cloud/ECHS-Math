Change in Tandem

How does an output respond as an input changes? In this lesson you will read, describe, compare, and construct relationships using verbal, numerical, graphical, and analytical representations.

AP exclusion statement

Do not spend instructional time distinguishing open versus closed interval notation when stating where a function is increasing or decreasing. That distinction is outside the AP Precalculus scope for this concept.

2. The Big Idea: Two Quantities Change Together

A function connects an input quantity to an output quantity. As the input changes, the output responds according to the function rule. That linked behavior is change in tandem.

1. Identify

What is the input? What are its units?

2. Identify

What is the output? What are its units?

3. Describe

As input increases, does output rise, fall, or stay constant?

4. Refine

Is the change becoming faster, slower, or approximately steady?

2.1 What makes a relation a function?

A function assigns each allowable input exactly one output. Different inputs may share the same output; one input may not have two different outputs in the same function.

Allowed

f(2)=9 and f(5)=9. Two inputs can have the same image.

Not a function

g(3)=4 and g(3)=10. One input cannot map to two outputs.

Domain = allowable input values   Range = output values actually produced

2.2 Independent and dependent variables

The amount of fuel F remaining in a generator is a function of operating time h.

Independent variable: h (hours). Dependent variable: F (fuel amount).

If F(6)=18, then after 6 hours of operation, 18 units of fuel remain.

2.3 Function notation

If y=f(x), then x is the input and f(x) is its output.

Let p(x)=2x²-5x+1.

InputOutput
x=-2p(-2)=19
x=0p(0)=1
x=3p(3)=4

Thus p(0)<p(3)<p(-2).

2.4 Image and preimage

Image

The image of input a is the single output f(a).

Ask: “Where does this input go?”

Preimage

The preimage of output L is the set of all inputs satisfying f(x)=L.

Ask: “Which input value(s) create this output?”

For f(x)=x²-4 on -3≤x≤3:

  • image of 2: f(2)=0;
  • preimage of 0: {-2,2};
  • preimage of 5: {-3,3}.

2.5 Equal functions

Two functions are equal only when they have the same domain and the same output for every input in that domain.

f(x)=5(x-2)+7 and g(x)=5x-3, both on all real numbers.

Because 5(x-2)+7=5x-3 for every real input, f=g.

p(x)=x²+1 on all reals and q(x)=x²+1 on x≥0.

Same formula, different domains, so p≠q.

3. Comparing Function Values: The Core of Covariation

Suppose a<b. Comparing f(a) and f(b) tells us how the outputs at those two inputs compare.

ComparisonMeaning
f(a)<f(b)The output at the larger input b is greater.
f(a)>f(b)The output at b is smaller.
f(a)=f(b)The two inputs have the same output; behavior between them is still unknown.

AP Trap: From f(a)<f(b) alone, you cannot conclude that f is increasing at every input between a and b. The function could rise, fall, and rise again.

Example: numerical representation

t (hours)012345
B(t) (%)1009183767065

For the listed values, battery charge decreases as time increases. Also, the successive decreases become smaller in magnitude. A careful AP statement is: “At the listed input values, increasing time corresponds to decreasing battery charge.”

A finite table does not prove behavior at every input between the listed data points unless additional information is given.

4. Increasing, Decreasing, and Constant Behavior

Increasing

For all a<b in the region, f(a)<f(b).

Decreasing

For all a<b in the region, f(a)>f(b).

Constant

Outputs stay the same. A horizontal segment is neither strictly increasing nor strictly decreasing.

How to read a graph

  1. Read from left to right as input increases.
  2. Locate where the output rises, falls, or stays level.
  3. State the regions with appropriate precision.
  4. If the graph is approximate, use “about” or “approximately.”

Do not confuse height with direction. A high point is not “increasing.” At a turning point, the graph changes from increasing to decreasing or vice versa.

5. Concavity: How the Rate of Change Is Changing

Concavity is different from increasing/decreasing behavior. It describes what happens to the rate of change as the input increases.

Concave up

The rate of change is increasing. Slopes become more positive or less negative.

Concave down

The rate of change is decreasing. Slopes become less positive or more negative.

BehaviorWhat the output doesWhat happens to steepness
Increasing, concave upRisesRises faster and faster
Increasing, concave downRisesRises more slowly
Decreasing, concave upFallsFalls more slowly
Decreasing, concave downFallsFalls faster and faster

Context example: A tank drains quickly at first, then more slowly. Volume is decreasing, but its rate of change is becoming less negative, so the graph is decreasing and concave up.

Major misconception: concave up does not mean “going up,” and concave down does not mean “going down.” Direction and concavity answer different questions.

6. Zeros and x-Intercepts

A zero is an input value c such that f(c)=0. The corresponding graph point is the x-intercept (c,0).

For f(x)=2(x+4)(x-1)(x-5), the zeros are -4,1,5, and the x-intercepts are (-4,0),(1,0),(5,0).

Precision: a zero is an input value; an x-intercept is a coordinate point.

If H(t) is a drone's height above launch level, then a zero of H represents a time when the drone is at launch level. A zero does not automatically tell you that the function changes sign there.

7. Four Representations of One Function

Graphical

Graph / curve / plotted points

Numerical

Table / listed values

Analytical

Formula / function rule

Verbal

Context / description

AP questions often ask you to move between representations. Your conclusion should match the precision of the representation provided.

If a graph is low resolution, do not report an exact transition value that the graph does not support. If a table gives only selected points, do not assume unseen behavior between rows.

8. Constructing a Graph from a Context

  1. Put the independent variable and units on the horizontal axis.
  2. Put the dependent variable and units on the vertical axis.
  3. Mark the starting output if given.
  4. Translate each verbal stage into increasing, decreasing, or constant behavior.
  5. Use concavity only when the description tells how the rate is changing.
  6. Show a zero only when the output is stated to become 0.

Worked story

A machine starts cool. Its temperature increases slowly at first, then faster; later it keeps rising but begins to level off near a stable temperature.

Stage 1: increasing and concave up. Stage 2: increasing and concave down. The graph should approach an approximately constant level.

A context graph is not a picture of the physical object. Its shape represents how two quantities vary together.

9. Complete AP Reading Routine

  1. Variables: identify input/output and units.
  2. Values: read or evaluate requested function values.
  3. Zeros: locate them if relevant.
  4. Direction: identify increasing/decreasing/constant regions.
  5. Concavity: describe how rate of change behaves when supported.
  6. Context: interpret the mathematics in the situation.
AP-quality sentence frame

“As the input _____ increases from/about _____ to _____, the output _____ [increases/decreases/remains approximately constant], and the rate of change [increases/decreases] when that conclusion is supported.”

10. AP-Style Practice

Original ECHS questions aligned to Topic 1.1. Reveal checks only after committing to an answer.

MCQ 1 · 1.1.A Function language

A function C(n) gives the total cost of purchasing n identical notebooks. Which statement is correct?

A. C is the input and n is the output.
B. n is dependent because cost depends on it.
C. n is independent and C(n) is dependent.
D. The variables cannot be identified.
Check answer
C. The number of notebooks is the input; total cost depends on it.
MCQ 2 · 1.1.A Precision of conclusions

Suppose f(2)=7 and f(8)=12. Which conclusion is guaranteed?

A. f is increasing on the entire interval.
B. f(2)<f(8).
C. f is concave up.
D. f has no zeros.
Check answer
B. The two known values justify only the direct comparison.
MCQ 3 · 1.1.B Concavity

A population is increasing, but the number added each year is getting smaller. Which description best fits the graph?

A. Increasing, concave up
B. Increasing, concave down
C. Decreasing, concave up
D. Decreasing, concave down
Check answer
B. The output rises while its rate of change decreases.
MCQ 4 · 1.1.A Equal functions

Two functions use the formula x²+3, but one has domain all real numbers and the other has domain x≥0. Which is correct?

A. Equal because formulas match.
B. Not equal because domains differ.
C. Equal only if ranges differ.
D. Not enough information.
Check answer
B. Equal functions require equal domains and equal outputs on that domain.
FRQ · Skills 2.B & 3.A Battery performance

A rechargeable battery's remaining energy E(t), in watt-hours, is measured at selected times.

t (h)012345
E(t)806858504440
  1. Identify the independent and dependent variables and units.
  2. Compare E(1) and E(4) and interpret the comparison.
  3. Describe the covariation shown by the listed values.
  4. The successive decreases become less negative. What qualitative concavity does the data suggest?
  5. State one limitation of using only this table to describe behavior between the listed times.
Scoring check

(a) t is independent in hours; E is dependent in watt-hours. (b) E(1)=68>44=E(4); at 1 hour the battery has 24 Wh more energy than at 4 hours. (c) At listed times energy decreases as time increases. (d) Decreasing, concave up is suggested because the decreases become smaller in magnitude. (e) The table does not determine every value or behavior between sampled times.

11. Challenge & Tricky Questions

These questions stay inside Topic 1.1 but force careful reasoning about what the evidence does—and does not—justify.

Challenge 1 · Endpoint trap

Construct a function with f(0)=1 and f(6)=9 that is not increasing on the entire interval from 0 to 6. Explain why your example disproves the claim that endpoint comparison determines monotonicity.

Challenge 2 · Same range, different functions

Give two different functions with the same domain and the same range that are not equal functions. Provide enough information to verify all three claims.

Challenge 3 · Multiple preimages

Construct a function graph for which the output 4 has exactly three preimages. Explain why the graph can still represent a function.

Challenge 4 · A zero with no sign change

Sketch a function with a zero at x=3 whose output is positive immediately on both sides of x=3. What does this show about what a zero does and does not imply?

Challenge 5 · Data ambiguity

A table gives f(0)=0, f(1)=1, f(2)=4, f(3)=9. Draw two qualitatively different graphs through all four points: one increasing throughout and one that is not increasing everywhere between the listed inputs. Explain why the table alone cannot distinguish them.

Challenge 6 · Construct from constraints

Sketch a function satisfying all of these conditions in one window: f(-2)=0 and f(4)=0; the function is increasing, then decreasing, then increasing; one increasing region is concave down; the final increasing region is concave up; and the output 3 has at least two preimages.

Challenge 7 · Precision

A low-resolution graph appears to flatten near x=5. Write one mathematically responsible conclusion and one statement that is too strong to justify from the visual alone. Explain the difference.
