Learning Objective

Describe how the input and output values of a function vary together by comparing function values, and construct a graph representing two quantities that vary with respect to each other in a contextual scenario.

This lesson includes prerequisite retrieval, worked examples followed by student turns, multiple representations, misconception analysis, calculator and no-calculator labels, complete solutions, and mastery evidence.
