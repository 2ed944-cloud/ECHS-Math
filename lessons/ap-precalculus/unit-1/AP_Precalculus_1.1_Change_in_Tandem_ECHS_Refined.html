Learn · AP Precalculus · Topic 1.1

One input must have one output

Different inputs are allowed to share an output.

x\longmapsto f(x)

A function assigns each input in its domain exactly one output. The range consists of outputs actually produced.

Pairs (1,4) and (2,4) are compatible with a function. Pairs (1,4) and (1,7) are not.

On a graph, a vertical line may meet the graph at most once. Several points on one horizontal line are allowed.

Learn · AP Precalculus · Topic 1.1

Name the quantities and their allowable values

A domain is a set of inputs; a range is the set of resulting outputs.

Water volume versus time

In the reservoir model, t is elapsed time in minutes, the independent variable. V(t) is volume in liters, the dependent variable.

The model runs from 0 through 8 minutes, so its domain is [0,8]. Its smallest volume is 10 L and largest is 34 L, so its range is [10,34].

The point (3,34) means that after 3 minutes, the reservoir contains 34 liters. It does not state a rate.

A finite domain is different

If R(n)=15n is revenue from selling up to 12 whole tickets, the domain is \{0,1,\ldots,12\}, not every real number between 0 and 12.

The range is \{0,15,30,\ldots,180\}.

When a table defines a finite function completely, use only its listed inputs. When it gives selected observations from a continuous setting, unlisted inputs may still belong to the domain.

Learn · AP Precalculus · Topic 1.1

Evaluate a value and interpret it

Replace every occurrence of the input variable before calculating.

Let T(h)=18+3h-h^2 for 0\le h\le4, where h is hours after noon and T(h) is a temperature in °C.

T(0)=18, T(2)=20, and T(4)=14.

At 2 p.m., the temperature is 20°C. The comparison T(2)>T(4) says it is warmer at 2 p.m. than at 4 p.m.

Those two values alone do not tell us everything that happened in between. Function notation names an output, not multiplication of two variables.

Learn · AP Precalculus · Topic 1.1

Start with an input or start with an output

An image is one output; a preimage is a set of inputs.

Image of a

Find f(a): the output paired with a specified input.

Preimage of L

Find every input satisfying f(x)=L, subject to the domain.

For f(x)=x^2-1 on [-3,3], the image of 2 is 3. The preimage of 3 is \{-2,2\}.

The preimage of −1 is \{0\}. The preimage of −2 is empty because the function never outputs −2 on this domain.

Learn · AP Precalculus · Topic 1.1

Equal functions need the same domain and outputs

A formula alone does not specify the entire function.

Equivalent rules, same domain

f(x)=2(x+3) and g(x)=2x+6, both on \mathbb R.

Distribution shows their outputs agree at every shared input; their domains agree, so the functions are equal.

A finite domain can make different rules agree

x^2 and |x| both give 1, 0, 1 on domain \{-1,0,1\}. They define equal functions on that domain.

Same rule, different domains

p(x)=x^2 on \mathbb R, and q(x)=x^2 on [0,\infty).

These are different functions: p(-2) is defined, but q(-2) is not.

Use an input as evidence

To show two functions on the same domain are unequal, find one input with different outputs. To establish equality, agreement at just a few sampled inputs is generally insufficient.

The words, rule, table and graph must describe the same input-output pairs.

Verbal → analytical

Numerical

The pairs are (0,10),(1,18),(2,26),(3,34).

Compare values without overstating the evidence

An endpoint comparison is different from behavior throughout an interval.

f(0)=1<9=f(6), but the graph falls from input 2 to input 4.

Learn · AP Precalculus · Topic 1.1

Read direction as the input increases

The sign of an output does not determine whether it rises or falls.

Increasing: whenever a<b in the interval, f(a)<f(b).

Decreasing: whenever a<b, f(a)>f(b).

Constant: all inputs in the interval have the same output.

A constant segment is neither strictly increasing nor strictly decreasing. Use simple “from a to b” language when describing these regions.

For −4 < x < −3, outputs are negative but increasing. For 0 < x < 1, outputs are positive but decreasing. At x = −3 and x = 1, the output is zero.

Ask separately: Where is the graph? and Which way does it move from left to right?

Learn · AP Precalculus · Topic 1.1

Concavity describes a changing rate

Keep output direction separate from whether the rate increases or decreases.

Concave up

The rate of change increases. A rising graph becomes steeper; a falling graph becomes flatter.

For a falling output, the sequence of changes −6, −4, −2 is increasing: each change is less negative.

Concave down

The rate of change decreases. A rising graph becomes flatter; a falling graph becomes steeper.

A function can increase while its rate decreases.

Four combinations

OutputRateShape
Rises fasterIncreasesConcave up
Rises more slowlyDecreasesConcave down
Falls more slowlyIncreasesConcave up
Falls fasterDecreasesConcave down

“Faster” describes the size of the change; the rate itself is signed. Always name the output direction too.

Learn · AP Precalculus · Topic 1.1

Read what a rate table actually tells you

Separate the sign of the rate from the way the rate changes.

Two different questions about a rate
InformationWhat it tells you about f
Rate is positive / negativef increases / decreases
Rate is increasing / decreasingGraph is concave up / concave down
Rate is constantGraph is a straight segment; a zero rate makes it horizontal

Worked comparison

On −10 < x < −6, suppose the rate is negative and increasing. A progression such as −12, −7, −3 becomes less negative. Outputs decrease, but the graph bends upward. On −6 < x < −2, a positive constant rate gives a straight rising segment.

These are descriptions throughout intervals. A few sampled rates alone would not establish behavior at every intervening input. When the question asks only about concavity, use increasing or decreasing rate; the sign is not enough.

Combine direction and concavity in two steps

Make one decision about output direction and a second about the bend.

Four combinations
RateOutputConcavityDescription
Positive, increasingIncreasingUpRising faster

Negative, increasingDecreasingUpFalling more slowly

Worked example

For equal input steps, imagine positive output changes of 11, 7 and 2, with the curve rising and flattening throughout. The output still increases because the changes stay positive. The rate decreases, so the graph is concave down.

The output may be above or below zero in any of these four cases. Read “f is decreasing” and “the rate of change of f is decreasing” as different statements.

Learn · AP Precalculus · Topic 1.1

Follow the rate through a turning point

A curve may change direction while its rate keeps changing in the same direction.

  1. Identify the entire interval being asked about.
  2. Read the graph from left to right: rising, horizontal at a smooth turning point, or falling.
  3. Decide whether the slope becomes larger or smaller across the interval.
  4. Check whether one statement holds throughout, including both sides of the turning point.

Worked comparison

A hill can have slope descriptions +6, +2, 0, −3, −8 from left to right. The rate keeps decreasing even though the output first increases and then decreases. Its graph is concave down across the hill.

A valley reverses that pattern: −8, −3, 0, +2, +6. The rate increases across the valley. Use qualitative steepness here; no derivative formula is needed.

Learn · AP Precalculus · Topic 1.1

Use a numerical pattern responsibly

Equal input spacing matters when comparing successive output changes.

At times 0, 1, 2, 3 and 4, a concentration has values 12, 9, 7, 6 and 5.5.

The successive changes are −3, −2, −1 and −0.5. The listed outputs fall by smaller amounts over equal time intervals.

This suggests decreasing, concave-up behavior. A finite table alone does not prove the shape between samples.

If input gaps are unequal, comparing raw output changes alone does not establish a pattern in rates. Topic 1.2 develops a quantitative comparison.

Learn · AP Precalculus · Topic 1.1

A zero is an input; an intercept is a point

Interpret an output of zero using the quantity named by the function.

If f(c)=0, the input c is a zero of f and (c,0) is an x-intercept.

For g(x)=(x+2)(x-1)(x-3) on \mathbb R, the zeros are −2, 1 and 3. The intercept points are (-2,0),(1,0),(3,0).

If the domain changes to [-1,4], −2 is no longer a zero of the stated function because it is not an allowable input.

If H(t) measures height above a launch level, H(t) = 0 means the object is at that level. It need not have stopped moving.

Make every graphical feature correspond to the quantities and conditions.

2. Place

3. Shape

4. Check

Learn · AP Precalculus · Topic 1.1

Connect circular motion to wall distance

Track shortest distance to a fixed wall, not distance traveled around the track.

  1. Label the horizontal axis elapsed time and the vertical axis shortest distance to the wall.
  2. Find the starting distance. Starting nearest the wall gives a minimum; starting farthest gives a maximum.
  3. One lap reproduces the distance pattern once. Half a lap exchanges nearest and farthest points.
  4. Check smoothness: at constant speed on a circular track, the wall distance turns smoothly at its extremes.

Worked example

A track of radius 1.5 m has a 0.5 m gap from the wall. The wall distance ranges from 0.5 m to 0.5 + 2(1.5) = 3.5 m. If a lap takes 6 s and the car starts nearest the wall, the first maximum occurs at 3 s and the first return to minimum at 6 s.

Distance to a wall is never negative. Total distance traveled keeps accumulating; wall distance can increase and decrease. Constant speed along the track does not make wall distance change at a constant rate. The simulation assumes a point-sized car, uniform circular motion and a straight wall outside the track; no trigonometric formula is required.

Learn · AP Precalculus · Topic 1.1

Infer a depth graph from a vessel

Constant volume inflow does not always mean constant depth increase.

Assume water enters at a constant volume per second, the vessel does not leak, and every horizontal cross-section is circular. Read the vessel from the bottom upward.

Link vessel shape to depth versus time
Area as depth increasesDepth behaviorGraph
Gets smallerRises fasterIncreasing, concave up
Gets largerRises more slowlyIncreasing, concave down
Stays constantRises steadilyA straight rising segment

Worked volume comparison

Adding 60 cm³ to a straight section of area 30 cm² raises the depth by 2 cm. The same amount in a section of area 10 cm² raises it by 6 cm. A narrow neck therefore produces a steeper depth graph than a wide body.

The outline of a vase is a width–height picture, not a depth–time graph. A bulb that first widens and then narrows produces a different sequence of bends from a body that narrows from its base. If the inflow changes, shape alone no longer determines the graph.

Use a graphing calculator to read a function

Check a value, inspect the window and describe features with appropriate precision.

Enter p(x)=0.08(x+4)(x-1)(x-5) on your GDC. Start with x from −5 to 6 and y from −6 to 6. Use the graph’s value or trace command to inspect an input.

Keep the factors in parentheses. Use extra stored digits for calculations and round a final answer only as requested. A display window can hide part of a function without changing its domain.

Learn · AP Precalculus · Topic 1.1

Interpret the ball’s height and the two clocks

Distinguish a time measured from release from a duration measured after the peak.

In a height model, the input is seconds after release and the output is height above the ground. The initial height is h(0). A maximum is the greatest physical height; the positive zero gives ground contact. Stop the model at first impact.

Worked timeline

If a calculator gives the maximum at 0.620 s after release and ground contact at 2.940 s after release, the descent lasts 2.940 − 0.620 = 2.320 s. “After release” and “after maximum height” use different starting events.

A ball thrown upward rises first. A ball released from rest begins at its maximum. In either case, the height graph can be concave down throughout.

Graphing-calculator method for the numerical questions

  1. Enter the given height function. Choose a window showing t = 0, the maximum and the positive zero; for these examples, try 0 ≤ t ≤ 5 and 0 ≤ h ≤ 35.
  2. TI-Nspire: Graphs → Menu → Analyze Graph → Maximum; bracket the peak. Use Analyze Graph → Zero and bracket the positive intercept.
  3. TI-84 Plus CE: Y=, then GRAPH; 2nd TRACE (CALC) → maximum or zero. Supply left and right bounds and a guess.
  4. Record the x-coordinate of the maximum, its y-coordinate, and the positive zero. Subtract the two times for descent duration.
  5. Keep stored calculator precision. Round only the final answer to three decimal places.

If the curve is still above ground at the right edge, widen the time window. A negative zero is not a physical time after release.

Calculator references: TI-Nspire graph analysis · TI-84 Plus CE zero command.
