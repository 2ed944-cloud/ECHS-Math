Rates of change

How much does the output change for each unit of input change?

A change of 90 liters is an amount. A change of 30 liters per minute is a rate.

Move between words, tables, graphs and formulas. Then use nearby intervals to estimate how quickly a quantity is changing at a point.

Learn · AP Precalculus · Topic 1.2

Name the quantities and read the interval

The order “output with respect to input” determines the units.

Input and output

In V(t), t is elapsed time in minutes and V(t) is volume in liters. On [2,5], the initial input is 2 and the final input is 5.

Read [2,5] as every input from 2 through 5. To calculate an interval average, we need its two endpoint outputs.

A function value such as V(5)=910 describes an amount at a time. It does not itself describe a rate.

Three questions

What changed? Volume.

With respect to what? Time.

Over which interval? Minute 2 through minute 5.

Keep a quantity’s value, its net change and its rate in separate lines of working.

Learn · AP Precalculus · Topic 1.2

First find the amount of change

Net output change is final output minus initial output.

A tank holds 820 L at minute 2 and 910 L at minute 5.

\Delta V=V(5)-V(2)=910-820=90

The volume change is 90 L. The elapsed time is 5-2=3 minutes.

A positive output change means a larger final output. A negative output change means a smaller final output.

Learn · AP Precalculus · Topic 1.2

“Per” turns a change into a rate

Divide the output change by the input change.

\text{Average rate on }[a,b]=\frac{f(b)-f(a)}{b-a},\quad a<b

For the tank, \frac{910-820}{5-2}=\frac{90}{3}=30 L/min.

A constant increase of 30 liters per minute for 3 minutes would produce the same net change of 90 liters. The actual rate may vary within the interval.

The input values must be distinct. A zero-width interval produces a zero denominator, not an average rate of zero.

Choose endpoints and compute the rate

Keep amount of change, elapsed time and average rate separate.

Learn · AP Precalculus · Topic 1.2

Keep subtraction order and units consistent

Reverse both endpoint orders together, and read units from top to bottom.

\frac{910-820}{5-2}=\frac{820-910}{2-5}=30. Reversing only one subtraction would incorrectly change the sign.

For V(t), the rate units are liters per minute. For C(q), the units are cost per item.

Learn · AP Precalculus · Topic 1.2

Explain what the signed average says

A whole-interval average summarizes endpoint change.

Positive

With a<b, a positive average implies f(b)>f(a). The endpoint changes have the same sign, even when we reverse the order of the inputs.

Negative

A negative average implies f(b)<f(a). The input and output changes have opposite signs.

Zero

A zero average implies f(b)=f(a).

A complete interpretation

From minute 5 to minute 8, tank volume decreased by an average of 20 liters per minute.

This states the interval, quantities, direction and units. It does not claim that exactly 20 liters left during each minute.

Positive outputs can have a negative rate. Negative outputs can have a positive rate.

Compare a flat graph with graphs that turn around.

Learn · AP Precalculus · Topic 1.2

Avoid claiming more than the average establishes

Interior behavior needs additional evidence.

Both averages on [0,4] equal (9-1)/4=2, but the functions differ between their endpoints.

A positive average does not prove the function increases throughout the interval. A zero average does not prove the function is constant.

Learn · AP Precalculus · Topic 1.2

Read two points, then compare their changes

The straight comparison shows the constant rate with the same net output change.

The comparison line rises 6 output units across 3 input units.

\frac{6-0}{4-1}=2

This straight line through two graph points is called a secant line. Its slope gives the same interval average computed from the endpoint values.

Read the axis scales and labeled coordinates. The visual steepness on a screen is not enough when scales differ.

Learn · AP Precalculus · Topic 1.2

Calculate from a formula before interpreting

Evaluate both endpoint outputs; subtract the entire values.

Worked example

For q(x)=x^2-3x+2, calculate the average rate on [1,4].

q(1)=1-3+2=0.

q(4)=16-12+2=6.

\frac{q(4)-q(1)}{4-1}=\frac{6-0}{3}=2

The average is 2 output units per input unit.

A common error

\frac{q(4)+q(1)}2 averages two output values. It does not calculate an average rate.

Another interval

On [0,2], q(0)=2 and q(2)=0, so the average rate is (0-2)/2=-1.

The two interval averages differ. Each is a summary of its own endpoint change.

Compare rates over unequal intervals

Normalize each output change by its own input change.

Learn · AP Precalculus · Topic 1.2

Recover an output from an average rate

Multiplying by the interval width recovers net output change.

f(b)=f(a)+r(b-a)

If f(2)=7 and the average rate on [2,6] is −3, then f(6)=7+(-3)(4)=-5.

The intermediate graph can vary; this endpoint calculation follows directly from the average-rate definition.

Join adjacent intervals

If rates are 5 on [0,2] and 1 on [2,8], their output changes are 10 and 6.

r_{[0,8]}=\frac{5(2)+1(6)}8=2

Add changes, then divide by total input change. The simple mean of the two rates is valid here only if the component intervals have equal lengths.

Learn · AP Precalculus · Topic 1.2

Use a small interval to investigate a point

An interval average is exact for its endpoints; its use at a point is an estimate.

A rate at a point describes how quickly the output is changing as the input varies near that point.

For a well-behaved graph near c, average rates on sufficiently small intervals containing c can approximate that rate, if a rate exists.

Use nearby points from both sides and compare more than one width. A whole-domain average may hide local variation.

Three nearby intervals

Left: [c-h,c], width h.

Right: [c,c+h], width h.

Centered: [c-h,c+h], width 2h.

Keep h>0. We use actual small intervals; we do not set h to zero.

Learn · AP Precalculus · Topic 1.2

Estimate near x = 2 from a table

The centered denominator includes both sides of the point.

Suppose f(1.9)=3.61,\ f(2)=4,\ f(2.1)=4.41.

Left average: (4-3.61)/0.1=3.9.

Right average: (4.41-4)/0.1=4.1.

Centered average: (4.41-3.61)/0.2=4.

These values support an estimate about 4 at x = 2. A narrower interval can provide further evidence if values remain accurate.

Learn · AP Precalculus · Topic 1.2

Check the agreement and the quality of the evidence

A single balanced interval is not always reliable.

Useful evidence

Several smaller nearby intervals produce stable estimates. Left and right calculations point toward the same value.

Report an estimated point rate using “approximately” and enough precision to distinguish the comparison requested.

Check the setting

Both endpoints must belong to the domain. At a domain endpoint, only intervals on the available side can be used.

Reasons to pause

A corner may have persistently different side rates. A jump may prevent nearby averages from supporting a finite point rate.

Rounded outputs may hide a small difference. A very small input width can magnify that rounding effect.

The challenge investigation returns to a centered estimate that looks convincing until its two sides are examined.

Learn · AP Precalculus · Topic 1.2

Greater rate and faster decrease mean different comparisons

Use the number line for signed values and absolute values for magnitude.

If estimated rates are −5 and −2, then -2>-5, but |-5|>|-2|.

The greater signed rate is −2. The faster decrease per input unit corresponds to −5.

A function’s larger output does not imply a larger local rate. A high water level may be falling slowly while a lower level is falling quickly.

Learn · AP Precalculus · Topic 1.2

Use the precision the representation supports

Keep exact interval calculations separate from local estimates.

Tables and graphs

Use labeled exact coordinates as exact values. If a graph only supports an approximate reading, do not report unjustified extra digits.

Selected measurements specify the displayed data, not every intervening value.

Calculators

Store full endpoint values. Subtract first, divide by the full input width, then round the final quotient.

Why tiny intervals can cause trouble

If both nearby displayed outputs round to 5.1, their displayed difference is zero.

The actual outputs may still differ. Dividing an inaccurate small difference by a tiny input width can produce a poor estimate.

A smaller interval is useful only alongside adequate precision and suitable local behavior.

Rates of Change
