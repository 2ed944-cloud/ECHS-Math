What makes a sequence arithmetic?

Consecutive terms change by a constant amount when the index increases by one.

Check every consecutive change

d=u_{n+1}-u_n

7,12,17,22,\ldots has common difference d=5.

31,27,23,19,\ldots has d=-4.

6,6,6,6,\ldots is arithmetic too: d=0.

Check spacing as well as values

Compare readings taken at equal intervals. A change across three index steps is not the common difference for one step.

A few observed values can suggest a pattern. Use an explicitly stated arithmetic assumption before treating that pattern as an exact rule.

When real measurements have slightly different first differences, an arithmetic model may still be a useful approximation.

A term and a sum answer different questions

Use the index, term and total notation consistently.

The sequence

u_1,u_2,u_3,\ldots is an ordered list. u_n is the value at position n.

For the pattern 24,30,36,\ldots, u_3=36.

The standard index starts at n=1. For a finite context, state the last permitted index.

The series and partial sum

S_n=u_1+u_2+\cdots+u_n

For the same pattern, S_3=24+30+36=90.

A total has the units of the quantities being added. Summing balances or sensor snapshots may not represent a meaningful new quantity; identify what the sum means.

Why the formula contains n − 1

Count the changes from the first term to the selected term.

An explicit formula

u_n=u_1+(n-1)d

Term 1 uses zero changes; term 2 uses one; term n uses n − 1.

For u_1=24,d=6, u_{12}=24+11(6)=90.

A recursive description

u_{n+1}=u_n+d,\qquad u_1\text{ given}

This tells you how to move from one term to the next. An explicit formula calculates a distant term directly.

u_n=24+6(n-1)=6n+18. The constant 18 in the simplified expression is not the first term; substitute n = 1.

Learn · IB Mathematics AI SL · 1.2A

Recover a sequence from separated terms

Divide the change in values by the number of index gaps.

Known terms

Suppose u_3=18 and u_8=43. These values are separated by five changes.

d=\frac{u_8-u_3}{8-3}=\frac{25}{5}=5

u_1=18-2(5)=8.

Check both conditions

u_n=8+5(n-1). Then u_3=18 and u_8=43, as required.

Do not use 43-18 as d: that is the combined change over five steps.

An equivalent method forms two equations in u_1 and d, then subtracts them.

Learn · IB Mathematics AI SL · 1.2A

Is the value actually a term?

An index must satisfy both the equation and the sequence’s domain.

A candidate term

In u_n=14+6(n-1), can a term equal 98?

14+6(n-1)=98 gives n=15, a valid positive integer.

For a target 100, the solution is n=15\frac13. It is not an index in this sequence.

Restrictions belong in the answer

A row number or count of complete weeks must be a whole number. Negative indices and fractional positions may satisfy an equation but fail the context.

For a finite sequence, also check whether the index exceeds the number of available terms.

A discrete sequence can lie along a straight-line pattern without being defined at every point on that line.

Learn · IB Mathematics AI SL · 1.2A

Find the first valid index

Treat “greater than” and “at least” as different conditions.

A strict threshold

Weekly targets start at 90 and increase by 35. Find the first target greater than 700.

90+35(n-1)>700 gives n>18.428\ldots.

The first index is 19: u_{18}=685\le700 and u_{19}=720>700.

Verify adjacent indices

Choose the first integer satisfying the original inequality, then check the previous integer.

For “at least,” equality is allowed. For decreasing sequences, the relevant boundary may be the last positive term.

If a term counts seats, items or litres remaining, reject values that violate the physical context.

1.2B · From a list to a total

A series adds the terms in the specified interval.

The row-total problem

Return to 12 rows with 24 panels in the first row and 6 additional panels in each next row.

The last row has 90 panels. Adding every row can be organized by pairing the first with the last.

24+90=30+84=36+78=114.

Use two copies of the sum

Write one copy forward and the other backward. Each column has the same total.

2S_n=n(u_1+u_n)

This approach works for odd or even n. It explains the formula without requiring a formal proof by induction.

Learn · IB Mathematics AI SL · 1.2B

Choose either arithmetic-sum formula

Use the first and last terms, or the first term and common difference.

When the last term is known

S_n=\frac n2(u_1+u_n)

S_{12}=\frac{12}{2}(24+90)=684 panels.

The total is the number of terms multiplied by their average.

When d is known

S_n=\frac n2[2u_1+(n-1)d]

S_{12}=\frac{12}{2}[48+11(6)]=684.

These formulas are equivalent because u_n=u_1+(n-1)d. Identify what is being added before choosing a sum.

Learn · IB Mathematics AI SL · 1.2B

Read every part of sigma notation

The lower and upper limits are inclusive.

A precise instruction to add

\sum_{k=1}^{5}[7+3(k-1)]

Start with k = 1 and finish with k = 5. The summands are 7,10,13,16,19.

Their sum is 65. The letter k is a temporary index; j or r can be used instead.

A shifted lower index

\sum_{k=3}^{7}(4k+1)

There are 7-3+1=5 terms. The first is 13 and the last is 29, so the sum is 105.

The upper limit alone does not count the terms when the lower limit is not 1.

Learn · IB Mathematics AI SL · 1.2B

Sum a selected block of terms

Remove everything before the first included term.

Use endpoints and a count

For u_n=10+4(n-1), add terms 5 through 11.

u_5=26,\quad u_{11}=50 and 11-5+1=7 terms.

\sum_{k=5}^{11}u_k=\frac72(26+50)=266

Or subtract two partial sums

\sum_{k=r}^{s}u_k=S_s-S_{r-1}

Here S_{11}-S_4=330-64=266.

Subtracting S_5 would remove the fifth term too. Use the index just before the included block.

Learn · IB Mathematics AI SL · 1.2B

Simple interest is a constant annual increase

The interest is calculated on the original principal each year.

Balance after t years

B_t=P+It,\qquad I=P\frac r{100}

For 5000 QAR at 3% simple interest, I=150 QAR per year and B_t=5000+150t.

After 4 years the balance is 5600 QAR; the interest earned is 600 QAR.

Time zero and term one

At t=0, the balance is the initial principal P.

If u_1 represents the first end-of-year balance, then u_1=P+I and u_n=P+I+(n-1)I=P+nI.

This model assumes the stated simple-interest arrangement and no other cash flows. It does not repeatedly apply the rate to an increasing balance.

Real measurements need an approximate model

Estimate a typical change and explain the limits of the prediction.

A stated estimation method

Readings at equal intervals are 10.0,13.1,16.0,19.2. Their differences are 3.1,2.9,3.2.

\widehat d=\frac{3.1+2.9+3.2}{3}=\frac{19.2-10.0}{3}

Keep the unrounded estimate while predicting; here \widehat d\approx3.07 to 3 significant figures.

Interpret before extending

A model anchored at the first observation uses u_n\approx u_1+(n-1)\widehat d.

This endpoint-based average is one stated estimation method, not a claim of a unique best-fitting model.

Separate the index step from time units. If readings are two hours apart, d is change per two-hour interval. Extrapolation assumes the pattern continues beyond the data.

Check the quantity, index and assumption

A plausible number can answer the wrong question.

Three common index errors

  • Using u_1+nd when the first index is 1.
  • Treating a change across six terms as a single common difference.
  • Counting s-r terms from r to s instead of s-r+1.

Three common modelling errors

  • Using u_n for a cumulative total.
  • Adding annual account balances as if they were new payments.
  • Claiming a noisy data set is exactly arithmetic, or extending a model beyond sensible physical limits.
