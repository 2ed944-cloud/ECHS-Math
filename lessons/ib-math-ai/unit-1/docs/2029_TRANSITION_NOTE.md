# Current course and first-assessment-2029 transition

This release is deliberately aligned to the current IB Mathematics: Applications and Interpretation SL course used by cohorts assessed through 2028. It therefore includes SL logarithms in Lesson 1.5.

For the revised course:

- first teaching: August 2027
- first assessment: May 2029
- logarithms are removed from Applications and Interpretation SL

Before assigning this package to a first-assessment-2029 cohort, hide or replace Lesson 1.5 and complete a full crosswalk against the final subject guide. The remaining lessons should also be rechecked because assessment structure and syllabus wording are changing.
