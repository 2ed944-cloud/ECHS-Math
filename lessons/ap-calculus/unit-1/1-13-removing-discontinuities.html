A repair has one possible height

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

To make a function continuous at x=a, its value must equal its finite two-sided limit: f(a)=\lim_{x\to a}f(x). If that limit is the real number L, defining or redefining f(a)=L repairs the discontinuity. The repair is unique because a function has only one value at an input. Changing the point value does not change the nearby values used to find the limit.

First find the limit without using the proposed point value. Then state the value needed for continuity and verify the continuity condition. An undefined function value alone does not prove that a repair exists.

Simplify nearby; keep the original exclusion

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

Factoring or rationalizing can reveal a removable discontinuity. For example, (x^2-9)/(x-3)=x+3 for x\ne3. The quotient and the line agree near 3, so the quotient has limit 6. The original quotient still has no value at 3; cancellation does not fill the hole automatically.

A continuous extension adds the ordered pair (3,6). If a remaining denominator is zero at another input, inspect that input separately. One formula can have both a repairable hole and an unrepairable discontinuity.

Match all three quantities at a join

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

For a piecewise function to be continuous at a join a, require \lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a). Evaluate each nearby branch at the join using its own expression. Use the branch whose inequality includes equality to determine the actual value, unless a separate point value is given.

When there are two joins, write a continuity equation at each one before solving the resulting system. Finally substitute the parameters back into every branch boundary; satisfying one join does not guarantee continuity at another.

Know when redefining a point cannot work

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

If the one-sided limits are different, there is no two-sided limit to use as the new value. A single point cannot connect two different approaching heights. If nearby outputs are unbounded or keep oscillating without approaching a number, no real point value can create a finite limit either.

Numerical samples may suggest the height of a hole, but a finite table alone cannot prove a limit. A formula, a stated limit, or sufficiently specified graph behavior must support an exact repair. A justification should identify the failed condition, not merely say that the graph “looks broken.”

Repair a rational function and retain its domain restriction

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

Let f(x)=(x^2+x-6)/(x^2-4), where the quotient is defined. Factor both polynomials: f(x)=(x+3)(x-2)/[(x-2)(x+2)]. For x\ne2,-2, this equals (x+3)/(x+2).

At x=2, the simplified denominator is nonzero, so \lim_{x\to2}f(x)=5/4. Define the extension by F(2)=5/4 and F(x)=f(x) elsewhere in the original domain. Then \lim_{x\to2}F(x)=F(2), proving continuity at 2. At x=-2, the simplified numerator approaches 1 while the denominator approaches zero; there is no finite limit to assign. The extension still excludes −2.

Solve two continuity equations

Determine values or parameters that make a function continuous, and justify when no repair by redefining one value is possible.

Suppose F(x)=x^2 for x\lt 1, F(x)=ax+b for 1\le x\le3, and F(x)=x+4 for x\gt 3. At the first join, continuity requires a+b=1. At the second, it requires 3a+b=7.

Subtracting the equations gives 2a=6, so a=3 and b=-2. Verify: both sides at 1 approach 1 and F(1)=1; both sides at 3 approach 7 and F(3)=7. Every branch is polynomial, so these boundary checks establish continuity for every real input.
