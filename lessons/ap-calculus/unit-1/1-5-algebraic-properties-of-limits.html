The finite limit laws

Both component limits use the same approach.

Assume \lim_{x\to c}f(x)=A and \lim_{x\to c}g(x)=B, with A and B finite.

Complete limit statements and conditions
LawConclusionCondition
Constant\lim_{x\to c}k=kk is constant.
Linear combination\lim_{x\to c}[pf(x)+qg(x)]=pA+qBp and q are constants. Includes sums and differences.
Product\lim_{x\to c}f(x)g(x)=ABBoth finite component limits exist.
Power\lim_{x\to c}[f(x)]^n=A^nn is a positive integer.
Quotient\lim_{x\to c}\frac{f(x)}{g(x)}=\frac ABB\ne0.

The same laws apply to \lim_{x\to c^-} or \lim_{x\to c^+} when their corresponding component limits satisfy the conditions.

Preserve the expression’s structure

Keep the target visible at every step.

Given \lim_{x\to2}f(x)=2, \lim_{x\to2}g(x)=-3, and \lim_{x\to2}h(x)=4:

Constant multiples and difference

\lim_{x\to2}[3f(x)-2g(x)]=3(2)-2(-3)=12.

Power then product

\lim_{x\to2}f(x)[g(x)]^2=2(-3)^2=18.

Sum then root

\lim_{x\to2}\sqrt{h(x)+5}=\sqrt{4+5}=3, since the limiting radicand is positive.

Check the real-root domain

The root and its radicand must make sense near the target.

Positive limiting radicand

If \lim_{x\to2}g(x)=9, then \lim_{x\to2}\sqrt{g(x)}=3. The radicand is positive sufficiently near 2.

Zero limiting radicand

\lim_{x\to0}\sqrt{x^2}=0: the expression is real on both sides. But \sqrt{x} is only real for x\ge0, so we explicitly write its available approach as \lim_{x\to0^+}\sqrt{x}=0.

Odd roots

If \lim_{x\to-1}g(x)=-8, then \lim_{x\to-1}\sqrt[3]{g(x)}=-2. A square root of g is not real sufficiently near −1.

Check the denominator before dividing

A zero denominator limit makes the quotient law unavailable.

A justified quotient

If \lim_{x\to2}f(x)=2 and \lim_{x\to2}g(x)=-3, then \lim_{x\to2}\frac{f(x)}{g(x)}=-\frac23, because the denominator limit is nonzero.

An inconclusive form

If both numerator and denominator limits are zero, “0/0” is a description of the substitution form. It is not a number or a final limit.

For example, the supplied identities x/x=1 and x^2/x=x for x\ne0 give different limits as x\to0. Knowing the two zero component limits alone cannot distinguish these outcomes.

General methods for rewriting expressions are developed in Topic 1.6.

Direct substitution follows from the laws

Check the expression before substituting the target.

For a polynomial P, \lim_{x\to c}P(x)=P(c), by the power, constant-multiple, and sum laws.

For polynomials P and Q with Q(c)\ne0, \lim_{x\to c}\frac{P(x)}{Q(x)}=\frac{P(c)}{Q(c)}.

Example: \lim_{x\to2}\frac{x^2+1}{x+1}=\frac53, because the denominator tends to nonzero 3.

Decision check

  • Polynomial: substitution is justified.
  • Finite numerator and nonzero denominator limit: use the quotient law.
  • Zero denominator limit: the quotient law cannot give a result.
  • Composite: locate the inner limiting input and check the outer function there.

A failed condition means that this theorem is unavailable. It does not by itself settle the limit.

Inside first, outside second

The outer function must be continuous at the inner limiting input.

If \lim_{x\to c}g(x)=L and F is continuous at L, then \lim_{x\to c}F(g(x))=F(L), provided the composite is defined near c on the relevant domain.

For \lim_{x\to2}g(x)=4 and F(u)=u^2+1, \lim_{x\to2}F(g(x))=F(4)=17.

The outer input here approaches 4; it does not approach the original x-target 2.

Knowing only F(4) does not establish outer continuity. Knowing only g(2) does not establish the inner limit.

When the inner function jumps

Take the original x-approach from the left and right separately.

Suppose \lim_{x\to c^-}g(x)=L_- and \lim_{x\to c^+}g(x)=L_+, where L_-\ne L_+.

If F is continuous at both inner destinations and the composite is defined nearby, then:

\lim_{x\to c^-}F(g(x))=F(L_-)

\lim_{x\to c^+}F(g(x))=F(L_+).

  1. Read the two inner side limits.
  2. Apply the outer function to each side using the appropriate limit laws.
  3. Compare the resulting outer limits.

If F(L_-)=F(L_+), the composite has that two-sided limit. If they differ, the composite limit does not exist.

Do not substitute “DNE” into F. A nonexistent inner two-sided limit is a reason to examine both sides, not an automatic answer for the composite.

Graph example · The composite limit exists

A jump can disappear after applying the outer function.

The inner graph jumps at x = 2. The filled point gives g(2) = 3.

The continuous outer function is F(u) = u².

\lim_{x\to2^-}g(x)=-1, so the one-sided power law gives \lim_{x\to2^-}F(g(x))=(-1)^2=1.

\lim_{x\to2^+}g(x)=1, so \lim_{x\to2^+}F(g(x))=1^2=1.

The composite sides agree: \lim_{x\to2}F(g(x))=1. The inner two-sided limit does not exist, while the composite limit does.

The point value F(g(2))=F(3)=9 is separate from the nearby limit.

Explore · AP Calculus AB / BC · Topic 1.5

Graph example · The composite limit does not exist

The same inner jump now produces different composite side limits.

Use exactly the same inner function g.

The continuous outer function is H(u) = u + 2.

\lim_{x\to2^-}g(x)=-1, so the one-sided sum law gives \lim_{x\to2^-}H(g(x))=-1+2=1.

\lim_{x\to2^+}g(x)=1, so \lim_{x\to2^+}H(g(x))=1+2=3.

The composite sides differ: \lim_{x\to2}H(g(x)) does not exist. Checking only one side would miss this conclusion.

In both graph examples, outer continuity justifies each side’s calculation at its own inner destination.

A condition audit before the answer

Check what is known before applying a theorem.

Components

Are the required component limits known and finite? Should I compare sides?

Denominator

Does its limit differ from zero?

Real domain

Is the root or reciprocal defined on the relevant nearby inputs?

Outer behavior

Where does the inside land, and is the outside continuous there?

An unavailable theorem does not automatically imply DNE. State only what the evidence establishes and use a different justified argument when necessary.
