Four mathematicians compare methods

A classroom story: when is substitution justified?

The graph reader

“I trace the nearby heights.”

The table builder

“I check values on both sides.”

The algebraist

“For polynomials, the limit laws justify substituting the target.”

The skeptic

“What if the denominator tends to zero, or the outside function jumps?”

The methods answer the same limit question from different evidence. Direct substitution is a theorem-based conclusion when its conditions hold. A hole, jump or zero denominator calls for a closer examination.

Roots have real-domain conditions

Odd roots accept every real input. Even roots need nonnegative inputs.

Positive limiting radicand

If g→9, then g is positive sufficiently near the target. The root limit is \sqrt9=3.

Zero limiting radicand

If g→0, use the actual real domain where g≥0. On that domain, √g→0 when the target is an accumulation point. To use a full punctured neighborhood, require g≥0 throughout it.

Negative limiting radicand

If g→−8, an even root is not real sufficiently near the target. A cube root remains real and tends to −2.

The denominator condition is essential

Use A/B only when the denominator limit B is nonzero.

Valid quotient

If f→2 and g→−3, then f/g\to-2/3. A nonzero denominator limit ensures g stays nonzero sufficiently near the target.

What if the denominator tends to zero?

The quotient theorem cannot be applied. The form 0/0 is inconclusive; a nonzero numerator limit divided by a zero denominator limit cannot produce a finite quotient limit.

Determine signs and nearby relationships before deciding on an infinite or nonexistent limit.

Substitution is a consequence of the laws

Start with the limit of x, then build polynomials and eligible quotients.

As x→c, x→c and each constant stays fixed. Powers, constant multiples and finite sums therefore give P(x)\to P(c) for every polynomial P.

If Q(c)≠0, the quotient law gives P(x)/Q(x)\to P(c)/Q(c).

Example: \lim_{x\to2}(x^2+1)/(x+1)=5/3, since the denominator tends to nonzero 3.

Check the form

  • Finite numerator / nonzero denominator: substitute.
  • Zero / nonzero: the limit is zero.
  • Nonzero / zero: inspect side behavior; no finite quotient limit.
  • Zero / zero: the form is indeterminate; investigate further.

The sign of an infinite one-sided limit depends on nearby signs, not on the symbol “division by zero.”

Investigation 5 · Is substitution justified?

Decide before calculating, then give the value when allowed.

State the reason

For a polynomial, cite the polynomial limit property. For a rational function, also verify the nonzero denominator. For a composite, check the outer function at the inner limiting value.

Inside first, outside second

The outer function receives the inner limiting input.

If g(x)\to L and F is continuous at L, then F(g(x))\to F(L), provided the composite is defined on the relevant nearby domain.

For g→4 and F(t)=t²+1, the outer input approaches 4; hence F(g)→17.

If only F(L) is known, the nearby outer behavior may still be unknown. A point value alone is not a continuity hypothesis.

A condition audit before the answer

Check what is known before applying a theorem.

Components

Are the required component limits known and finite? Should I compare sides?

Denominator

Does its limit differ from zero?

Real domain

Is the root or reciprocal defined on the relevant nearby inputs?

Outer behavior

Where does the inside land, and is the outside continuous there?

An unavailable theorem does not automatically imply DNE. State only what the evidence establishes and use a different justified argument when necessary.
