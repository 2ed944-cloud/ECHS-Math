Start with three pieces of evidence

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

At an interior input c, record \lim_{x\to c^-}f(x), \lim_{x\to c^+}f(x), and f(c) separately. An open circle describes the nearby branch; a filled point gives the assigned value. A function can be defined at c and still be discontinuous there.

If the one-sided limits agree at a finite number L, the two-sided limit is L. Continuity then requires the assigned value to equal L. If the one-sided behaviors disagree, assigning a different value at the single input c cannot change those behaviors.

Removable discontinuities: a finite target with a missing or misplaced value

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

A discontinuity is removable when the finite two-sided limit L exists but f(c) is undefined or is different from L. Both branches approach the same height. The graph has a hole, possibly accompanied by a filled point at another height.

For example, r(x)=(x^2-9)/(x-3) equals x+3 for x\ne3. Its limit at 3 is 6, although its original formula is undefined at 3. Cancellation identifies nearby behavior; it does not put an excluded input back into the original domain.

Jump and infinite discontinuities require different evidence

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

A jump occurs when both one-sided limits are finite but unequal. For a step that approaches 1 from the left and 4 from the right, the two-sided limit does not exist. Matching the point value to either branch does not eliminate the jump.

An infinite discontinuity occurs when at least one one-sided limit is +\infty or -\infty. These symbols describe unbounded growth, not real function values. For 1/x, the left-hand limit at 0 is -\infty and the right-hand limit is +\infty. For 1/x^2, both are +\infty. Neither discontinuity is removable.

Classify only what the evidence supports

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

Not every discontinuity is a jump or an infinite discontinuity. The bounded function \sin(1/x) oscillates without approaching a single height as x\to0; its discontinuity is nonremovable but is neither a finite jump nor an infinite discontinuity.

Use an exact formula, stated limits, or a graph whose features are specified. A finite table of sampled outputs can suggest behavior but cannot by itself prove a limit or continuity. When classifying rational expressions, first factor and examine the remaining denominator: a canceled factor may leave a hole, while an uncanceled zero may produce unbounded behavior.

One rational expression, two different discontinuities

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

Classify the discontinuities of r(x)=(x^2-x-6)/(x^2-4). The original denominator is zero at -2 and 2. Factoring gives r(x)=(x-3)(x+2)/[(x-2)(x+2)]=(x-3)/(x-2) for x\ne-2,2.

At -2, the reduced denominator is nonzero, so \lim_{x\to-2}r(x)=(-5)/(-4)=5/4. The original value is undefined: this is removable. At 2, the numerator tends to -1. The reduced denominator tends to zero through negative values from the left and positive values from the right. Thus the left limit is +\infty, the right limit is -\infty, and the discontinuity is infinite.

A point value cannot bridge a jump

Identify and classify discontinuities using finite limits, one-sided limits, function values, and unbounded behavior.

Let f(x)=x+2 for x<1, let f(1)=7, and let f(x)=5-x for x>1. The left-hand limit is 1+2=3; the right-hand limit is 5-1=4. These are unequal finite values, so the discontinuity at 1 is a jump.

The value 7 is not either one-sided limit. Changing it to 3, 4, or any other real number still leaves the same unequal limits. A correct explanation cites both limits and their inequality, rather than merely saying that the graph is broken.
