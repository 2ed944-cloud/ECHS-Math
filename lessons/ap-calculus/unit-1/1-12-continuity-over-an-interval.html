Continuity on an interval includes every relevant point

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

A function is continuous on an open interval when it is continuous at every point in that interval. On a closed interval [a,b], it must be continuous at every interior point, right-continuous at a, and left-continuous at b: \lim_{x\to a^+}f(x)=f(a) and \lim_{x\to b^-}f(x)=f(b).

Only the side inside the interval is needed at an endpoint. The same rule applies to an included endpoint of a half-open or unbounded interval. Infinity is not a real endpoint value, so interval notation always uses parentheses beside \pm\infty.

The original domain determines where to split

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

Start by finding excluded inputs. A rational function is continuous wherever its original denominator is nonzero. If (x^2-1)/(x-1) is given without a separate definition at 1, the input 1 remains excluded even though the expression simplifies to x+1 for other inputs. Its maximal intervals of continuity are ( -\infty,1) and (1,\infty).

Here, a maximal interval means an interval contained in the function’s domain that cannot be enlarged while preserving continuity. Split at every excluded interior input and every failed piecewise join. Do not combine disconnected pieces into one interval that contains missing points.

Combine restrictions for roots, logarithms, and quotients

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

For real outputs, an even-root radicand must be nonnegative, a logarithm’s argument must be strictly positive, and every denominator must be nonzero. For f(x)=\sqrt{x+2}/(x-1), these restrictions give x\ge-2 and x\ne1. Known continuity rules then give the intervals [-2,1) and (1,\infty), including −2 by right-continuity.

Apply all restrictions together. A square root in a denominator must be strictly positive, because a zero radicand would give a zero denominator. A nonzero denominator by itself does not guarantee a real logarithm or square root.

Check piecewise joins and endpoints explicitly

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

Continuity of each branch handles inputs inside that branch, but it does not automatically handle a boundary. At an interior join, compute both one-sided limits and the assigned value. The interval can pass through the join only when all three agree.

At a requested interval’s endpoint, use the branch lying inside that interval. A function can be continuous on [0,2] even if it has a jump at 0 when viewed on the whole real line: right-continuity is enough at the left endpoint of [0,2]. State the interval before deciding which limit condition applies.

Find maximal intervals and keep a root endpoint

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

Consider f(x)=\sqrt{x+3}/(x^2-4). The root requires x\ge-3. The denominator excludes -2 and 2. Therefore the real domain is [-3,\infty) with those two inputs removed.

The root is continuous on its domain, and the denominator polynomial is continuous and nonzero within each remaining piece. The maximal intervals of continuity are [-3,-2), (-2,2), and (2,\infty). To justify the included endpoint, f(-3)=0/5=0 and \lim_{x\to-3^+}f(x)=0. Neither excluded denominator input can be included.

An endpoint uses only the side inside the interval

Determine intervals on which a function is continuous using known continuous functions, domain restrictions, and one-sided endpoint conditions.

Let g(x)=1 for x<0, and g(x)=x+3 for x\ge0. On [0,2], every interior input uses a polynomial branch. At the left endpoint, \lim_{x\to0^+}g(x)=3=g(0). At the right endpoint, \lim_{x\to2^-}g(x)=5=g(2). Therefore g is continuous on [0,2].

The left-hand limit at 0 is 1, so g is not continuous at 0 as an interior point of its full real domain. These conclusions are consistent: continuity on the specified closed interval imposes only right-continuity at its left endpoint.
