Learning goals

Read the table in a deliberate order

A nearby output is evidence; it is not automatically the limit.

1. Locate

Identify the target input c and check which values lie on each side.

2. Order

Read toward decreasing distance from c, not simply toward a larger number.

3. Compare

Estimate the output trend on each side before comparing them.

4. Qualify

Use supported digits and distinguish a numerical estimate from a proof.

Do not average the input and output coordinates, two incompatible side limits, or the value at the target with nearby outputs.

The center is not an approach row

A limit can exist when the target value differs or is undefined.

A table for a limit should use inputs close to the target. If a center value is supplied, label it separately.

Changing that single value leaves every non-target table entry unchanged. Removing it does not remove the evidence nearby.

For a quotient undefined at the target, an error at that exact input answers a different question from the limit estimate.

A useful distinction

Estimate: nearby outputs appear to approach 4.

Assigned point: f(2) = 9, or f(2) is undefined, if stated.

Unknown point: no value at 2 is supplied, so the table does not determine it.

“Not supplied” does not mean “undefined.” A function may have a value that the table simply does not list.

Calculator settings are part of the method

Use valid nearby inputs and preserve enough digits.

Before generating a table

  1. Identify the target and the domain of the expression.
  2. Use explicitly chosen inputs on both sides where available.
  3. For standard calculus trigonometric expressions, use radians.
  4. Keep extra internal digits and round the final estimate.

When the display looks suspicious

If multiple different inputs display as the target, increase input precision. If outputs look identical, inspect more output digits.

Subtraction of nearly equal numbers can lose numerical accuracy. Do not assume the smallest possible step always gives the best estimate.

Compare several reasonable input distances. Algebraic methods and equivalent-expression techniques are developed in later lessons.

Finite samples support an estimate

A limit statement describes more inputs than a finite table can list.

A table can provide strong numerical evidence. It cannot, by itself, specify the value at every unlisted input arbitrarily close to the target.

Use wording such as “the entries suggest” or “the estimated limit is” when only finite samples are known.

If a full model is supplied, use the table to explore it and additional reasoning to establish its exact behavior.

Three safeguards

  1. Inspect both sides where available.
  2. Vary the sample choices and check sufficient precision.
  3. Distinguish an observed trend from a claim about every sufficiently close input.

More rows can improve an estimate. They cannot logically turn a finite sample into complete information about an arbitrary unknown function.

Explain a deceptive sampling list

Use a second family to test the first impression.

For g(x)=\sin(\pi/x), the positive inputs 1/n give outputs 0 for every positive integer n.

A student concludes the right-hand limit at zero is 0.

The positive inputs 2/(4n+1) also approach 0, but their outputs equal 1. The inputs 2/(4n+3) approach 0 with outputs −1.

Thus outputs at positive inputs arbitrarily close to zero do not settle near one value. The right-hand limit is DNE. The zero-only samples were an unrepresentative choice.

Challenge · AP Calculus AB / BC · Topic 1.4

Challenge · hide a different limit by rounding

Construct two numerical trends that look identical at low precision.

Construct one function with left-hand limit 1 and right-hand limit 1.0004 at zero. Choose three sufficiently close inputs on each side so every output rounds to 1.00 at two decimal places.

Use f(x) = 1 + x for x < 0 and f(x) = 1.0004 + x for x > 0.

Choose left inputs −0.0001, −0.00001, −0.000001 and matching positive right inputs. Every output rounds to 1.00 at two decimal places, although the limiting heights differ.

The two-sided limit is DNE. Rounded agreement is not exact agreement.

Challenge · AP Calculus AB / BC · Topic 1.4

Challenge · match the table, change the limit

Use unlisted inputs to show what a finite table leaves open.

A table lists f(1.9) = 3.9, f(1.99) = 3.99, f(2.01) = 4.01 and f(2.1) = 4.1.

Construct a function matching all four entries whose limit at 2 is 8.

Define g(x) = x + 2 at exactly the four listed inputs. Define g(x) = 8 at every other input.

Whenever 0 < |x − 2| < 0.01, x is none of the four listed inputs, so g(x) = 8 throughout that punctured neighborhood. Its limit at 2 is 8.

The same finite table can be compatible with different limiting behavior.
