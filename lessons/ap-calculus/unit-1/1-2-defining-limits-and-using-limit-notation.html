Read every part of the limit statement

The input target and the limiting output have different jobs.

\lim_{x\to c}f(x)=L
Input variablex

The quantity that varies.

Target inputc

The input approached, below the limit symbol.

Output expressionf(x)

The values we observe as the input varies.

Limiting outputL

The value those nearby outputs approach.

Read it aloud: “The limit of f(x), as x approaches c, equals L.” The arrow concerns inputs. The equality names a limiting output.

Example: \lim_{t\to3}T(t)=18. The time approaches 3; the temperature approaches 18. This statement alone does not tell us the temperature at exactly time 3.

What “approaches” really requires

A limit describes all sufficiently close non-target inputs.

\lim_{x\to c}f(x)=L

We can make the outputs as close to L as we wish by restricting x to be sufficiently close to c, with x\ne c, within the function’s domain.

As close as we wish: a smaller requested output gap can require a smaller input neighborhood.

All sufficiently close inputs: a few favorable sample points are not enough.

Non-target inputs: the value at c is a separate matter.

Two useful examples

For the nearby rule f(x)=x+2 at c = 2, |f(x)-4|=|x-2|. Keeping x within 0.01 of 2, but not equal to 2, keeps the output within 0.01 of 4.

For a constant nearby rule g(x)=5, the outputs already equal 5. That is certainly as close to 5 as any requested tolerance.

A limit may be zero. Nearby values may already equal the limit. The input is not required to move through time or eventually reach its target.

Translate the meaning, including units

A limit of an amount has the units of that amount.

Temperature near an instant

\lim_{t\to3}T(t)=18, where t is measured in minutes and T(t) in degrees Celsius.

Complete interpretation: as time approaches 3 minutes, the temperature approaches 18 °C.

This statement does not specify T(3). It also does not say that temperature changes by 18 °C each minute.

Your turn

Translate \lim_{t\to6}P(t)=24, where t is time in seconds and P(t) is pressure in kilopascals.

As time approaches 6 seconds, the pressure approaches 24 kilopascals.

The target is a time; the limit is a pressure. Pressure per second would describe a rate, which this statement does not provide.

A table can suggest more than it proves

Distinguish a pattern in sampled values from a limit statement.

Four measurements of an otherwise unknown function
x1.91.992.012.1
f(x)4.94.995.015.1

The entries suggest outputs approaching 5 as x approaches 2. They do not specify f(2), and they do not describe every unlisted input.

Make a precise claim

Supported: “The data suggest a limit of 5.”

Too strong: “These four samples prove the limit is 5.”

Extra information that helps: a complete nearby rule, or a stated description covering all sufficiently close inputs.

Later lessons develop estimation from graphs and tables. Here, your goal is to interpret the statement and the strength of the evidence.

Read a one-sided approach

A short bridge to the graphical work in Topic 1.3.

Notation bridge
\lim_{x\to c^-}f(x)=L

Use input values less than c: approach from the left.

\lim_{x\to c^+}f(x)=L

Use input values greater than c: approach from the right.

The superscript indicates an input direction. It does not state whether the output is positive, negative, increasing or decreasing.

A negative target

To approach −2 from the right, use −1.9, −1.99, −1.999, … . These numbers are all greater than −2.

From the left, use −2.1, −2.01, −2.001, … . These numbers are all less than −2.

If a model only has nonnegative time inputs, write t\to0^+ when describing positive times approaching 0. Do not invent negative-time values.

At an interior target, a finite two-sided limit requires agreement.

Two-sided limit at 2—

Exact branch definitions

For x < 2, use L+(x-2)/2. For x > 2, use R+(x-2)/2. At x = 2, use the assigned point value. L and R are controlled independently above.

Write DNE for a limit that does not exist

Use a reason, not an average of incompatible outputs.

Three different answers

A number: a finite limiting output, including zero.

DNE: the requested limit does not exist. Here, unequal one-sided limits justify that conclusion.

Undefined: a requested function value has not been assigned or is outside the domain.

In these answer fields, use DNE for a nonexistent limit and undefined for a missing function value. A missing function value can coexist with a finite limit.

Write two statements, then justify each

Use the definition of the function to support the distinction.

Let p(x)=\begin{cases}x+1&x\ne-1\\5&x=-1\end{cases}.

State the limit of p(x) as x approaches −1. State p(−1). Explain how the rule supports both answers.

1. Nearby rule: for x\ne-1, the output is x + 1.
2. Limit: as x approaches −1 from either side, x + 1 approaches 0. Thus \lim_{x\to-1}p(x)=0.
3. Point value: the second case explicitly gives p(-1)=5.
4. Explanation: the limit uses nearby non-target inputs, while the function value uses the assigned rule at −1.

Challenge · AP Calculus AB / BC · Topic 1.2

Challenge · build your own counterexample

A complete construction demonstrates what a statement cannot guarantee.

Construct two functions f and g that both have limit 3 as x approaches 1, but satisfy f(1)=0 and g(1)=6.

Give each function a complete rule, and describe how their graphs agree and differ.

One choice is f(x)=\begin{cases}3&x\ne1\\0&x=1\end{cases} and g(x)=\begin{cases}3&x\ne1\\6&x=1\end{cases}.

Every non-target output is 3, so both limits equal 3. Both graphs have an open circle at (1,3); f has a filled point at (1,0), and g has one at (1,6).

Other nearby rules approaching 3 also work. This construction shows that equal limits do not force equal values at the target.

Challenge · AP Calculus AB / BC · Topic 1.2

Challenge · the same table, different limits

Show concretely why finitely many samples cannot settle every limit.

A table lists only inputs 1.9, 1.99, 2.01 and 2.1, with outputs 4.9, 4.99, 5.01 and 5.1.

Function f follows x + 3 at every input. Function g takes those same four listed values, but equals 8 at every other input.

For f, \lim_{x\to2}f(x)=5, since nearby outputs follow x + 3.

For g, every input satisfying 0<|x-2|<0.01 is different from the four listed inputs. All of those outputs equal 8. Therefore \lim_{x\to2}g(x)=8.

The functions agree at every entry of the finite table but have different limits. Information about unlisted, closer inputs matters.

Bring the notation and the meaning together

Use precise language before moving to graphical limit estimation.

\lim_{x\to c}f(x)=L

As inputs approach c, the nearby outputs approach L. The statement concerns all sufficiently close non-target domain inputs and does not by itself determine f(c).

At an interior target with inputs on both sides, a finite two-sided limit requires the two one-sided limits to agree.
