What a graph can tell you

Read limits, point values and the limits of the picture itself.

Learning goals

  1. Estimate left-hand and right-hand limits from a graph.
  2. Compare them to decide whether a finite two-sided limit exists.
  3. Read open and filled points correctly.
  4. Recognize unequal sides, unbounded behavior and persistent oscillation.
  5. Explain how scale and resolution can hide important details.

Your route

Begin with a four-question routine. Use six investigations to trace and construct graphs, examine windows, and classify behavior.

Then work through 16 AP-style MCQs, three written tasks, two challenges and an exit ticket.

Suggested use: one class for the core investigations, then practice and written reasoning in a second class or independent session. No calculator is required for the supplied graphs.

A missing point can have a clear nearby limit

Use the branch heights to explain the result.

At x = −1, both approaching branches reach the open circle at height 2. There is no filled point at that input.

\lim_{x\to-1^-}f(x)=2, \lim_{x\to-1^+}f(x)=2, so \lim_{x\to-1}f(x)=2.

The function value f(−1) is undefined. A limit need not fill the hole.

Agreement concerns the nearby heights

A point assignment cannot make different one-sided limits agree.

The left branch approaches 1. The right branch approaches 4. Therefore the two-sided limit at 2 does not exist.

\lim_{x\to2^-}f(x)=1\ne4=\lim_{x\to2^+}f(x)

The filled point at height 3 is not a compromise between the branches. Their average 2.5 is not a limit either.

Write DNE and give the reason: the one-sided limits are unequal.

Explore · AP Calculus AB / BC · Topic 1.3

A corner does not block a limit

Heights can agree even when the curve changes direction.

Both branches of f(x)=|x| approach height 0 as x approaches 0. Thus the two-sided limit is 0.

A corner describes a change in the graph’s direction. The limit question here asks where the output heights approach.

Do not replace a function-value limit question with a slope or derivative question. Differentiability is developed later.

Match your conclusion to the evidence

A graphing window is a representation, not the entire function.

Inspect the scale

Check how much one tick interval represents on each axis. Equal screen distances can represent very different numerical distances.

If the picture only supports an approximate height, write an estimate. Do not report extra decimal places that the graph cannot resolve.

Check missing details

A small hole, a narrow jump or rapid oscillation may be invisible at the current scale. A graphing device may also connect sample points across an excluded input.

Use a closer window and more precise coordinates where helpful. A complete model or additional reasoning is needed for claims that a finite picture cannot settle.

Infinity describes unbounded behavior

Be precise about finite limits and infinity notation.

\lim_{x\to0}1/x^2=+\infty says that the outputs grow without bound as the inputs approach 0 from either side.

There is no finite real limit. Infinity is not a large real number and does not assign a value at x = 0.

For −1/x², both sides decrease without bound, described by −∞.

For 1/x, the left side tends to −∞ and the right side to +∞. The two-sided limit is DNE.

In answer fields, use infinity or -infinity when asked to describe unbounded behavior, and DNE when the requested two-sided limit has incompatible sides.

This lesson recognizes the graphical behavior. Systematic vertical-asymptote analysis is developed in Topic 1.14.

Repeated wiggles are not the deciding test

Ask whether the nearby outputs settle near one height.

Persistent size

For sin(1/x), inputs arbitrarily close to 0 can give output 1, and others can give output −1. These separated heights prevent convergence to one output.

For example, positive inputs x_n=1/(\pi/2+2\pi n) give 1, while y_n=1/(3\pi/2+2\pi n) give −1.

Shrinking size

For x sin(1/x), the magnitude of the output is no greater than |x|. The oscillations shrink inside an envelope approaching zero.

The limit is 0, even though the graph continues to wiggle. The formal squeeze theorem appears later; here the envelope explains the graphical estimate.

Challenge · AP Calculus AB / BC · Topic 1.3

Challenge · the same value, different limits

Construct a counterexample with complete graph conditions.

Build two graphs with f(0) = g(0) = 4, but \lim_{x\to0}f(x)=1 and \lim_{x\to0}g(x)=-2.

Use f(x) = 1 for x ≠ 0 and f(0) = 4. Use g(x) = −2 for x ≠ 0 and g(0) = 4.

The first graph has a hole at (0,1), the second at (0,−2), and both have a filled point at (0,4). The nearby heights determine the different limits.

Challenge · AP Calculus AB / BC · Topic 1.3

Challenge · a picture that seems convincing

Find a claim that the visible pixels cannot guarantee.

A calculator screen appears to show the line y = x + 2 through x = 1. A student concludes both the limit and the function value must be 3.

One function is x + 2 everywhere. Another equals x + 2 except that its value at 1 is 6, or it is undefined at 1.

A coarse sampled trace may fail to display the isolated change. All have limit 3 at 1, but the point values differ. The complete function definition resolves information the screen might miss.
