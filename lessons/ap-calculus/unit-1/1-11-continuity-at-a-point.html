The definition is an equality with conditions

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

A function is continuous at an interior point c when \lim_{x\to c}f(x)=f(c). This compact equality includes three requirements: f(c) is defined, the two-sided limit exists as a finite real number, and the limit equals the function value.

Check the requirements separately when evidence comes from different representations. Writing only “the limit exists” misses the assigned value. Writing only “the function is defined” misses the nearby behavior. A complete justification connects the finite common limit to the actual function value.

Find the limit before comparing it with the point

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

At a boundary between piecewise formulas, compute \lim_{x\to c^-}f(x) using the formula for inputs less than c, and \lim_{x\to c^+}f(x) using the formula for inputs greater than c. If the one-sided limits agree at L, the two-sided limit is L. Then read the branch that includes equality to find f(c).

A center-only assignment does not affect either one-sided limit. Conversely, two different formulas can define a continuous function when their limiting values and the assigned boundary value agree. The formulas do not need to look alike.

Use known continuous functions with their hypotheses

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

Polynomials are continuous at every real input. Rational functions are continuous wherever their denominators are nonzero. Sine, cosine, and exponential functions are continuous on their domains. Roots and logarithms are continuous on their real domains; domain restrictions still matter.

If f and g are continuous at c, then their sum, difference, and product are continuous there. Their quotient is continuous there when g(c)\ne0. For a composition, check that the inner function is continuous at the input and the outer function is continuous at the resulting inner value. Do not invoke a theorem while skipping its domain or denominator condition.

Write a justification that identifies the actual issue

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

For a continuous piecewise function, a useful sentence is: “Both one-sided limits at c equal L, and f(c)=L; therefore f is continuous at c.” For a discontinuous function, state which requirement fails and provide the values that prove it.

A corner does not prevent continuity: |x| has both one-sided limits equal to its value 0 at the origin. A finite table of outputs is suggestive rather than conclusive, unless additional exact information is supplied. Infinity is not a real function value that can satisfy the definition of continuity.

Verify all three conditions for a piecewise function

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

Let f(x)=x^2+1 for x<1, f(1)=2, and f(x)=3-x for x>1. First, the value f(1)=2 is defined. Second, the left limit is 1^2+1=2 and the right limit is 3-1=2, so the two-sided limit exists and equals 2.

Finally, \lim_{x\to1}f(x)=2=f(1). All three conditions hold, so f is continuous at 1. If only the center value were changed to 6, the same limit would exist but the equality would fail.

Determine which value makes the definition true

Determine whether a function is continuous at a point, and justify the conclusion using the definition of continuity.

Let g(x)=(x^2-1)/(x-1) for x\ne1, with g(1)=k. Factoring gives g(x)=x+1 for every nearby input other than 1. Therefore \lim_{x\to1}g(x)=2.

The definition requires k=2. With that choice, the value is defined and equals the finite limit, so continuity follows. Cancellation alone would not prove continuity of the original quotient at 1: the explicit assignment is what supplies the missing value.
