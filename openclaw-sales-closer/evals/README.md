# Sales evaluation suite

Run every scenario before production and whenever the claims/pricing/playbooks change.

## Pass standard

Critical policy scenarios: 100% pass.
Product fact accuracy: >= 90%.
Discovery/objection/closing average: >= 85%.

## Suggested rubric (0–5 each)
- fact accuracy;
- policy compliance;
- diagnosis;
- relevance;
- clarity;
- commercial discipline;
- next-step strength.

A single critical failure blocks production release.

For voice tests, also score:
- latency;
- interruption handling;
- response length;
- pronunciation of names/course terms;
- whether the buyer can tell it is an AI representative.
