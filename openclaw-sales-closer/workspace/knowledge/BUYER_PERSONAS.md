# Buyer personas

## 1. Head of Mathematics / Department Lead
Primary concerns:
- curriculum coverage;
- teacher workload;
- quality/consistency of resources;
- targeted intervention;
- assessment;
- student engagement.

Discovery:
- Which courses create the most preparation burden?
- How do teachers currently assign differentiated practice?
- How do you identify who needs intervention before the next assessment?
- Which part of your current stack is most fragmented?

Best demo:
Teacher Dashboard → Skill Analysis → targeted assignment → Practice Studio → Test Generator → student journey.

## 2. Principal / School Director
Primary concerns:
- measurable value;
- adoption;
- institutional visibility;
- operational risk;
- budget;
- implementation.

Discovery:
- What outcome would make a platform investment successful this year?
- Is the priority academic consistency, teacher efficiency, intervention, parent visibility, or a combination?
- How would a purchase be approved?

Best demo:
Role-based architecture → school control → teacher evidence → student pathway → family view.

## 3. Digital Learning / IT Lead
Primary concerns:
- identity;
- data flow;
- hosting;
- security;
- support;
- integration.

Discovery:
- What authentication/provisioning model is required?
- What data must stay under school control?
- Which integrations are mandatory vs optional?
- What security documentation is required for vendor review?

Best demo:
Admin role + account flow + architecture. Do not make compliance claims beyond verified documentation.

## 4. AP/IB Coordinator
Primary concerns:
- curriculum alignment;
- question quality;
- student readiness;
- teacher consistency.

Discovery:
- Which courses and levels are in scope?
- Which units are hardest to resource?
- How are timed practice and remediation handled now?

Best demo:
Course path → interactive lessons → focused practice → assessment/recovery.

## 5. Procurement / Finance
Primary concerns:
- scope;
- term;
- price;
- risk;
- contractual clarity;
- renewal.

Discovery:
- What procurement process and dates apply?
- Is a pilot required?
- Who owns educational and technical approval?
- What documentation must accompany the offer?

Best demo:
Minimal. Summarize validated value and move to commercial terms.

## 6. Teacher champion
Primary concerns:
- ease of use;
- lesson quality;
- time saved;
- student workflow.

Best demo:
teacher-to-student workflow end-to-end.

## Qualification tiers

A — strong:
- clear problem;
- target users/courses known;
- decision path known;
- implementation need inside 6 months;
- stakeholder willing to schedule discovery/demo.

B — develop:
- problem exists but decision process/timing unclear.

C — nurture:
- curiosity only, no defined need/timing.

D — disqualify:
- request is outside product scope;
- seeks restricted third-party content;
- no authority/route to a legitimate buyer;
- only wants free resources with no commercial intent.
