# Student learning sequence

1. The teacher assigns the student to a class with a course key.
2. The student signs in and sees only courses from current class memberships.
3. The student completes a lesson inside the guarded lesson page.
4. Focused practice for that lesson unlocks.
5. Attempts update mastery, mistake recovery, review timing, XP, levels and badges.
6. Mastery evidence identifies the next recommended skill.
