Methodology guardrails

What this system means—and what it does not

1. External evidence

MAP mathematics provides standardized achievement/growth evidence. The system does not claim NWEA officially maps a RIT score to an IB course.

2. Programme evidence

MYP Mathematics criteria add evidence of knowing, investigating, communicating and applying mathematics in context.

3. Pathway-specific evidence

An original diagnostic fills prerequisite gaps that one external score does not capture sufficiently for AA/AI pathway decisions.

4. Explainable index

The V1 result is a 0–100 readiness index with visible component scores, evidence completeness, confidence and limiting skills—not a predicted probability.

5. Action loop

Gaps create targeted preparation tasks. New evidence can move the readiness trajectory, so the system avoids permanent labels.

6. Validation

Completed local DP outcomes can later test correlation, classification performance and observed success by readiness band before predictive claims are considered.
