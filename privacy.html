Privacy

Current platform model: no student account or central learner database is required. Lesson bookmarks, completion marks and Practice Studio attempts are stored in the browser on the device being used.

Information stored locally

The platform may use browser storage to remember selected courses, lesson bookmarks, completion status, appearance preferences, practice attempts, answers and locally generated test results. This information remains on that browser unless a user clears it.

Information not collected by this static release

This GitHub Pages release does not include a platform-operated account system, advertising tracker, payment system or central analytics database. It does not sell learner information.

External resources

Some lessons link to external video, graphing, document or publisher services. Opening an external service is subject to that provider’s privacy terms. External resources are identified as links and open separately where appropriate.

Service worker and offline storage

The installable web application may cache platform files and previously opened pages so that parts of the site remain available offline. Cached files can be removed through the browser’s site-data or application settings.

Future accounts

If cloud accounts, class rosters or cross-device progress are introduced later, this notice must be updated before those features enter production. The new release must explain the data collected, its purpose, retention, access controls and deletion process.

Managing local data

Users can reset Practice Studio attempts from the Progress page and reset lesson progress from the course portal. Browser settings can remove all stored site data.
